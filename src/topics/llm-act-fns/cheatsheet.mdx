## 逐个函数

<Bento columns={4}>
  <Card span="2x1" title="Sigmoid">

    $f(x)=\sigma(x)=\frac{1}{1+e^{-x}}$

    $\frac{df(x)}{dx}=\sigma(x)(1-\sigma(x))$

    值域：$(0,1)$；典型位置：各类 gate、MoE 路由

    <ActFnPlot fns={["sigmoid"]} label="Sigmoid" />
  </Card>
  <Card span="2x1" title="Tanh">

    $f(x)=\tanh(x)$

    $\frac{df(x)}{dx}=1-\tanh^2(x)$

    值域：$(-1,1)$；典型位置：soft-capping $c\tanh(x/c)$

    <ActFnPlot fns={["tanh"]} label="Tanh" />
  </Card>
  <Card span="2x1" title="ReLU">

    $f(x)=\max(0,x)$

    $\frac{df(x)}{dx}=\mathbb{1}[x>0]$

    值域：$[0,\infty)$；典型位置：稀疏推理

    <ActFnPlot fns={["relu"]} label="ReLU" />
  </Card>
  <Card span="2x1" title="Squared ReLU">

    $f(x)=\max(0,x)^2$

    $\frac{df(x)}{dx}=2\max(0,x)$

    值域：$[0,\infty)$；典型位置：Nemotron FFN

    <ActFnPlot fns={["relu2"]} label="Squared ReLU" />
  </Card>
  <Card span="2x1" title="GELU">

    $f(x)=x\,\Phi(x)$

    $\frac{df(x)}{dx}=\Phi(x)+x\,p(x)$

    值域：$[-0.17,\infty)$；典型位置：GeGLU 的 gate

    <ActFnPlot fns={["gelu"]} label="GELU" />
  </Card>
  <Card span="2x1" title="SiLU">

    $f(x)=x\,\sigma(x)$

    $\frac{df(x)}{dx}=\sigma(x)(1+x(1-\sigma(x)))$

    值域：$[-0.28,\infty)$；典型位置：SwiGLU 的 gate

    <ActFnPlot fns={["silu"]} label="SiLU" />
  </Card>
  <Card span="2x1" title="Softplus">

    $f(x)=\log(1+e^x)$

    $\frac{df(x)}{dx}=\sigma(x)$

    值域：$(0,\infty)$；典型位置：Mamba 步长、参数约束

    <ActFnPlot fns={["softplus"]} label="Softplus" />
  </Card>
  <Card span="2x1" title="SiTU gate">

    $f(x)=\beta_1\tanh(x/\beta_1)\,\sigma(x)$

    $\frac{df(x)}{dx}=(1-\tanh^2)\sigma+\beta_1\tanh\cdot\sigma(1-\sigma)$

    值域：$\approx[-0.27,\,\beta_1)$，$\beta_1=4$；典型位置：Kimi K3 FFN

    <ActFnPlot fns={["situ"]} label="SiTU gate" />
  </Card>
</Bento>
