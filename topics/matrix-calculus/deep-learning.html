引言

训练一个模型，就是反复调整参数使损失变小。优化器每更新一次参数，都需要先知道损失对每个参数的导数：这个参数增大时，损失增大还是减小，变化多快。

单变量微积分里，导数描述的是一个数的变化引起另一个数变化多少。损失对一个参数的导数也是这个意思：参数是一个标量（一个数），损失是一个标量。但模型里的参数以矩阵的形式存放，每一层的输出是向量或矩阵，我们要一次算出损失对整个矩阵的导数，中间还要经过向量对向量的导数。把导数的定义从标量对标量扩展到标量对矩阵、向量对向量，这部分内容称为矩阵微积分。

PyTorch 这样的框架用 loss.backward() 完成全部求导，不需要手写推导。它使用的方法是反向模式自动微分。这个方法有一个基本结论：算出损失对全部参数的导数，开销不超过一次前向计算的一个小常数倍，与参数的个数无关，Griewank 和 Walther 称之为 cheap gradient principle[2]。由于这个结论，反向传播可以用于有几十亿个参数的模型。本文说明这个结论是怎么来的：沿一个 decoder-only Transformer 的计算图，给出 backward 在每一步用到的求导规则，以及这些规则合起来为什么不需要构造比数据更大的中间量。

本文假定读者了解 Transformer 的各个模块，用 PyTorch 训练过模型，微积分已经生疏。

本文使用的模型

下图是一个 decoder-only Transformer 做语言模型训练时，从输入 token 到损失的完整计算过程。每个方框是一次计算，每个圆角框是一份数据，框里标着它的形状。$T$ 是序列长度，$d$ 是模型宽度，$V$ 是词表大小，$N$ 是 Decoder 的层数。图中省略了 batch 维度。

图的输入是整数 token 编号，输出是标量损失 $L$，训练要求的是 $L$ 对图中每个权重矩阵的导数。求导沿箭头的反方向进行，每经过一个方框，用这个方框对应的求导规则算一次。图上的 FP32 和 BF16 标记是计算精度：权重以 FP32 保存，进入矩阵乘法之前转换成 BF16，这个转换没有参数，但反向传播要经过它；softmax 和 cross-entropy 在 FP32 里算。

本文的例子大多取自 SwiGLU FFN 和 GQA attention 两个方框，下面两个折叠块给出它们的定义。

什么是 SwiGLU FFN

FFN 对序列里的每个位置独立计算，所以下面只写一个位置的向量 $\mathbf{x} \in \mathbb{R}^{d}$：

$$\mathbf{h} = \big(\mathrm{Swish}(\mathbf{x}W_{gate}) \otimes \mathbf{x}W_{up}\big)\,W_{down}$$

三个权重矩阵：$W_{gate}$ 和 $W_{up}$ 都是 $d \times d_{ff}$，$W_{down}$ 是 $d_{ff} \times d$。$\otimes$ 表示逐元素相乘。Swish 逐元素作用在向量上，对每个数做的是 $\mathrm{Swish}(z) = z\,\sigma(z)$，其中 $\sigma(z) = \dfrac{1}{1+e^{-z}}$ 是 sigmoid 函数。

计算顺序：$\mathbf{x}$ 分别乘两个矩阵，得到两个 $\mathbb{R}^{d_{ff}}$ 中的向量；一个经过 Swish，然后和另一个逐元素相乘；结果乘 $W_{down}$，回到 $\mathbb{R}^{d}$。Llama、Qwen、Mistral 这些模型的 FFN 都是这个结构。

这个式子包含矩阵乘法、逐元素乘和逐元素函数三种运算。

什么是 GQA Attention

Attention 让每个位置的向量能读取它前面所有位置的信息。输入 $X$ 是 $T \times d$ 的矩阵，每一行是一个位置。

每个 query head $i$（一共 $n_h$ 个）有自己的 $W_Q^{(i)}$，形状 $d \times d_h$。key 和 value 只有 $n_{kv}$ 组，每组 $W_K^{(j)}$ 和 $W_V^{(j)}$（都是 $d \times d_h$）被 $n_h / n_{kv}$ 个 query head 共用。这是 Grouped-Query Attention 和普通 multi-head attention 的唯一区别。

对一个 query head $i$，设它所属的组是 $j$：

$$Q_i = XW_Q^{(i)},\qquad K_j = XW_K^{(j)},\qquad V_j = XW_V^{(j)}$$ $$A_i = \mathrm{softmax}\!\left(\frac{Q_iK_j^{T}}{\sqrt{d_h}} + M\right) V_j$$

$M$ 是 causal mask，把每个位置后面的位置置为 $-\infty$，让它只能看到自己和前面的位置。softmax 对矩阵的每一行独立作用。所有 head 的 $A_i$ 按列拼接成 $T \times n_h d_h$，再乘 $W_O$（$n_h d_h \times d$）。

这里有两处结构在求导时需要单独处理。softmax 的每个输出依赖同一行的全部输入，它的导数不是对角矩阵；本文的模型省略了 RMSNorm，在这个模型里 softmax 是唯一一个这样的运算。一组 K/V 权重被多个 head 共用，求它的导数时要把每个 head 传回的梯度相加。

什么是导数

先看最简单的情形：一个输入 $x$，一个输出 $y = f(x)$，两者都是标量。

我们先用有限的变化量来定义导数。$x$ 变到 $x + \Delta x$ 时，$y$ 从 $f(x)$ 变到 $f(x+\Delta x)$，两个变化量的比值是

$$\frac{\Delta y}{\Delta x} = \frac{f(x+\Delta x) - f(x)}{\Delta x}$$

几何上，这个比值是 $f$ 的图像上过 $x$ 和 $x+\Delta x$ 两点的直线的斜率，这条直线称为割线。

这个比值随 $\Delta x$ 改变。取 $f(x) = x^3$，在 $x = 1$ 处：$\Delta x = 1$ 时比值是 $7$，$\Delta x = 0.1$ 时是 $3.31$，$\Delta x = 0.01$ 时是 $3.0301$。$\Delta x$ 越小，比值越接近 $3$。下图的两个滑块分别控制 $x_0$ 和 $\Delta x$，把 $\Delta x$ 从 $1$ 减小到 $0.001$，可以看到割线的斜率逐渐接近 $3$。

$\Delta x$ 趋于零时，割线趋于一条确定的直线，这条直线是 $x_0$ 处的切线。切线的斜率不再依赖 $\Delta x$，这个斜率就是 $f$ 在 $x_0$ 处的导数，记作 $f'(x_0)$。取极限之后的比值记作 $\dfrac{dy}{dx}$，字母 $d$ 表示无穷小的变化量。把比值改写成乘法：

$$dy = f'(x)\,dx$$

这个式子称为微分形式：输入变化 $dx$，输出变化 $f'(x)\,dx$。本文以它作为导数的定义，向量和矩阵的导数在后面也写成这个形式。

$x_0$ 取不同位置时切线的斜率不同，所以 $f'$ 本身也是 $x$ 的函数，图的下半部分画的是它。对 $x^3$ 有 $f'(x) = 3x^2$，对 $\sin x$ 有 $f'(x) = \cos x$。

在模型里，损失 $L$ 是全部参数的函数。对其中一个参数 $w$，导数 $\dfrac{\partial L}{\partial w}$ 给出 $w$ 增大时 $L$ 的变化方向和变化率，优化器用这个数更新 $w$。这里用 $\partial$ 而不用 $d$，因为 $L$ 还有其他输入，对 $w$ 求导时它们保持不变。这种导数称为偏导数，下一章给出定义。

深度学习中导数的形状

模型里被求导的量有三种形状：标量、向量、矩阵。输入三种、输出三种，一共九种组合。求导的结果要放下每个输出分量对每个输入分量的导数，所以输出有 $m$ 个分量、输入有 $n$ 个分量时，结果有 $m \times n$ 个数。

下表列出九种组合，每一格给出结果的形状和模型里的一个例子。

标量 $y$ 标量$$\frac{dy}{dx}$$例：$\mathrm{Swish}(z)$ 对 $z$。 向量，$n$ 个数，称为梯度$$\frac{\partial y}{\partial \mathbf{x}} = \Big[\frac{\partial y}{\partial x_1}\ \ \frac{\partial y}{\partial x_2}\ \ \cdots\ \ \frac{\partial y}{\partial x_n}\Big]$$例：损失 $L$ 对某一个位置的 logits 向量。 矩阵，$p \times q$，和 $W$ 同形状$$\Big(\frac{\partial y}{\partial W}\Big)_{ij} = \frac{\partial y}{\partial W_{ij}}$$例：损失 $L$ 对 $W_{down}$。训练最终要求的是这一格。

训练最终需要的结果全在第一行。损失是标量，所以损失对任何变量的导数都与该变量同形状：$\frac{\partial L}{\partial 标量} \in R$；$\frac{\partial L}{\partial \mathbf{x}} \in R^{|x|}$; $\frac{\partial L}{\partial \mathbf{W}} \in R^{d \times d_{ff}}$，这就是为什么 PyTorch 里 w.grad 的形状总是与 w 相同。

表中三维和四维数组的三个灰格（向量-矩阵、矩阵-向量、矩阵-矩阵）只出现在中间步骤。损失对 $W_{down}$ 的导数，按链式法则要经过损失对 $\mathbf{h}$ 的导数和 $\mathbf{h}$ 对 $W_{down}$ 的导数两步，后一步就是第二行最后一格的三维数组。反向传播不构造这个数组，而是直接算出两步合并后的结果，链式法则一章说明怎么做。

本文写向量对向量的导数时，行对应输出，列对应输入，上表 Jacobian 一格就是这样排的，这种排法称为 numerator layout。有些资料采用转置的排法，称为 denominator layout。别处的公式形状与本文不一致时，先检查这一点。

对向量和矩阵求导，最后一步都是对单个数求导，所以先把本文用到的标量规则列出来。这些规则读者在微积分课上都见过，这里只列结果。

函数只有一个参数时，$\dfrac{d}{dx}f(x)$ 常简写成 $f'(x)$，本文在标量部分也这样写；出现多个变量后改用完整写法，因为 $f'$ 没有标明对哪个变量求导。

$\dfrac{d}{dx}$ 是一个运算符，输入一个函数，输出另一个函数。它对加法可以拆开，常数因子可以提到它前面，所以对复杂表达式求导可以先拆分、分别求导、再组合：

$$\frac{d}{dx}\,9(x + x^2) = 9\,\frac{d}{dx}(x + x^2) = 9\Big(\frac{d}{dx}x + \frac{d}{dx}x^2\Big) = 9(1 + 2x) = 9 + 18x$$

后面对向量和矩阵求导用的也是这个做法：把表达式拆成已有规则覆盖的部分，分别求导，再按形状组合。

sigmoid 与 Swish 的导数

Swish 是两个函数的乘积：$\mathrm{Swish}(x) = x \cdot \sigma(x)$。按乘积法则：

$$\mathrm{Swish}'(x) = 1 \cdot \sigma(x) + x \cdot \sigma'(x)$$

把 $\sigma'(x) = \sigma(x)\,(1-\sigma(x))$ 代入：

$$\mathrm{Swish}'(x) = \sigma(x) + x\,\sigma(x)\,(1-\sigma(x)) = \sigma(x)\,\big(1 + x\,(1-\sigma(x))\big)$$

在上一节的图里选 $\mathrm{Swish}(x)$，可以对照切线斜率和这个式子的取值，$x = 0$ 处两者都是 $0.5$。

向量微积分与偏导数入门

上一章的函数只有一个输入。模型里的函数都有多个输入，例如 LM head 的一个 logit $z_j = \sum_k x_k W_{kj}$，它依赖 $d$ 个输入 $x_k$ 和 $d$ 个权重 $W_{kj}$。我们需要梳理清楚：对其中一个求导时，其他输入怎么处理。

偏导数

$f(x, y) = 3x^2 y$ 有两个输入，变化可以沿 $x$，也可以沿 $y$。我们先只让一个输入变化。

固定 $y$，只让 $x$ 变化，$f$ 就是 $x$ 的单变量函数，上一章的方法可以直接用：它的图像在 $x$ 处的切线斜率，就是 $x$ 变化时 $f$ 的变化率。这个斜率称为 $f$ 对 $x$ 的偏导数，记作 $\dfrac{\partial f}{\partial x}$。

计算时把 $y$ 当作常数，按复习表里常数倍一行处理：

$$\frac{\partial}{\partial x}\,3x^2y = 3y \cdot \frac{d}{dx}x^2 = 3y \cdot 2x = 6xy$$

固定 $x$，只让 $y$ 变化，得到 $f$ 对 $y$ 的偏导数：

$$\frac{\partial}{\partial y}\,3x^2y = 3x^2 \cdot \frac{d}{dy}y = 3x^2$$

符号 $\partial$ 读作「偏」。它和 $d$ 的区别是：$\partial$ 表示函数还有其他输入，求导时它们保持不变。对只有一个输入的函数，$\dfrac{\partial f}{\partial x}$ 与 $\dfrac{df}{dx}$ 相同。

下图左边是 $f(x, y)$ 的取值，黑点是选定的位置 $(x_0, y_0)$。右边两张图是过这个点、分别固定 $y = y_0$ 和固定 $x = x_0$ 切出的两条单变量曲线，各带一条切线，两条切线的斜率就是两个偏导数。

梯度

训练时全部参数同时变化，所以我们还要知道 $x$ 变化 $dx$、$y$ 同时变化 $dy$ 时，$f$ 变化多少。答案是两个偏导数各自的贡献相加：

$$df = \frac{\partial f}{\partial x}\,dx + \frac{\partial f}{\partial y}\,dy$$

相加成立的条件是变化量为无穷小。这时先让 $x$ 变化、再让 $y$ 变化，和两者同时变化的结果相同：前一步 $f$ 变化 $\dfrac{\partial f}{\partial x}\,dx$，后一步再变化 $\dfrac{\partial f}{\partial y}\,dy$。变化量有限时这个式子只是一阶近似，上图最后三行给出了真实的 $\Delta f$、按这个式子算出的近似值，以及两者之差，$\Delta x$、$\Delta y$ 越大，差越大。

把两个变化量写成一个向量 $d\mathbf{x} = [\,dx\ \ dy\,]$，两个偏导数也排成一个向量：

$$\nabla f = \Big[\,\frac{\partial f}{\partial x}\ \ \frac{\partial f}{\partial y}\,\Big] = [\,6xy\ \ 3x^2\,]$$

这个向量称为 $f$ 的梯度，$\nabla$ 读作 nabla。于是

$$df = \nabla f \cdot d\mathbf{x}$$

与微分形式 $dy = f'(x)\,dx$ 对照，$f'(x)$ 的位置换成了梯度，乘法换成了点积。输入有 $n$ 个分量时，梯度就是 $n$ 个偏导数排成一行，对应形状表里标量对向量一格。损失 $L$ 的梯度 $\nabla L$ 由损失对每个参数的偏导数组成，优化器沿 $-\nabla L$ 的方向更新参数，每个参数用到的只是自己那一个偏导数 $\dfrac{\partial L}{\partial w}$。

LM head 的偏导数

回到 LM head。它对一个位置做的是 $\mathbf{z} = \mathbf{x} W_{out}$，其中 $\mathbf{x} \in \mathbb{R}^{d}$，$\mathbf{z} \in \mathbb{R}^{V}$。第 $j$ 个 logit 展开是

$$z_j = \sum_{k=1}^{d} x_k\,W_{kj}$$

对其中一个输入 $x_k$ 求偏导时，其余的 $x$ 和全部 $W$ 都当作常数，和式里只有含 $x_k$ 的一项留下，导数是 $W_{kj}$。对一个权重 $W_{kj}$ 求偏导同理，留下的是 $x_k$：

$$\frac{\partial z_j}{\partial x_k} = W_{kj},\qquad \frac{\partial z_j}{\partial W_{kj}} = x_k$$

以上求的是单个 $z_j$ 的梯度。$\mathbf{z}$ 有 $V$ 个分量，每个分量各有一个梯度，把 $V$ 个梯度逐行排起来，得到一个 $V \times d$ 的矩阵：

$$\frac{\partial \mathbf{z}}{\partial \mathbf{x}} = \begin{bmatrix} \nabla z_1 \\ \nabla z_2 \\ \vdots \\ \nabla z_V \end{bmatrix} = \begin{bmatrix} \dfrac{\partial z_1}{\partial x_1} & \cdots & \dfrac{\partial z_1}{\partial x_d} \\ \vdots & & \vdots \\ \dfrac{\partial z_V}{\partial x_1} & \cdots & \dfrac{\partial z_V}{\partial x_d} \end{bmatrix}$$

矩阵微积分

上一章的梯度是标量对向量的导数。模型里每一步的输出都是向量或矩阵：LM head 一次算出 $V$ 个 logit，Swish 一次作用在 $d_{ff}$ 个数上。所以还需要向量对向量的导数。

Jacobian

上一章结尾的矩阵完整描述了 $\mathbf{z} = \mathbf{x}W$ 里输出对输入的依赖：输入有 $d$ 个分量，输出有 $V$ 个分量，一共 $V \times d$ 个偏导数，第 $j$ 行第 $i$ 列是 $\dfrac{\partial z_j}{\partial x_i}$，即输入的第 $i$ 个分量变化时，输出的第 $j$ 个分量的变化率。这个矩阵称为 Jacobian，记作 $J$：

$$J = \begin{bmatrix} \dfrac{\partial z_1}{\partial x_1} & \dfrac{\partial z_1}{\partial x_2} & \cdots & \dfrac{\partial z_1}{\partial x_d} \\[8pt] \dfrac{\partial z_2}{\partial x_1} & \dfrac{\partial z_2}{\partial x_2} & \cdots & \dfrac{\partial z_2}{\partial x_d} \\[4pt] \vdots & \vdots & & \vdots \\[4pt] \dfrac{\partial z_V}{\partial x_1} & \dfrac{\partial z_V}{\partial x_2} & \cdots & \dfrac{\partial z_V}{\partial x_d} \end{bmatrix},\qquad J_{ji} = \frac{\partial z_j}{\partial x_i}$$

一行对应一个输出 $z_j$，它就是 $z_j$ 的梯度，给出 $z_j$ 对每个输入分量的偏导数。一列对应一个输入 $x_i$，给出 $x_i$ 变化时每个输出分量的变化率。行对应输出，列对应输入，这是第一章说的 numerator layout。

对 $\mathbf{z} = \mathbf{x}W$，上一章已经算出每一格：$\dfrac{\partial z_j}{\partial x_i} = W_{ij}$。所以 $J_{ji} = W_{ij}$，也就是

$$J = W^{T}$$

矩阵乘法的 Jacobian 是权重矩阵的转置。它不依赖 $\mathbf{x}$，因为 $\mathbf{z}$ 是 $\mathbf{x}$ 的线性函数，各处的变化率相同。下图用 $d = 2$、$V = 3$ 的例子列出各项，左下 $\partial \mathbf{z} / \partial x_1$ 和 $\partial \mathbf{z} / \partial x_2$ 两行按列排起来就是 $J = W^T$：

输入的变化是向量 $d\mathbf{x}$，输出的变化是向量 $d\mathbf{z}$。$dz_j$ 等于 $J$ 的第 $j$ 行与 $d\mathbf{x}$ 的点积，$V$ 个分量合起来是矩阵乘向量：

$$d\mathbf{z} = J\,d\mathbf{x}$$

$J$ 在这个式子里的位置，与标量情形中 $f'(x)$ 的位置相同。

逐元素运算的 Jacobian

FFN 里 Swish 作用在向量 $\mathbf{a} \in \mathbb{R}^{d_{ff}}$ 上，得到 $\mathbf{h} \in \mathbb{R}^{d_{ff}}$，$h_i = \mathrm{Swish}(a_i)$。它的 Jacobian 是 $d_{ff} \times d_{ff}$ 的矩阵，其中非对角元全为零：$h_j$ 只由 $a_j$ 算出，与 $a_i$（$i \neq j$）无关，所以 $\dfrac{\partial h_j}{\partial a_i} = 0$。对角元是复习表里的标量导数 $\mathrm{Swish}'(a_j)$。因此

$$\frac{\partial \mathbf{h}}{\partial \mathbf{a}} = \begin{bmatrix} \mathrm{Swish}'(a_1) & 0 & \cdots & 0 \\ 0 & \mathrm{Swish}'(a_2) & \cdots & 0 \\ \vdots & & \ddots & \vdots \\ 0 & 0 & \cdots & \mathrm{Swish}'(a_{d_{ff}}) \end{bmatrix} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)$$

$\mathrm{diag}(\mathbf{v})$ 表示以向量 $\mathbf{v}$ 为对角线的方阵。对每个分量分别作用同一个标量函数的运算称为逐元素运算，sigmoid、指数、平方都属于此类，它们的 Jacobian 都是对角矩阵，对角线上是对应的标量导数。

两个向量之间的逐元素运算同理。SwiGLU 中间那一步 $\mathbf{h} = \mathbf{a} \otimes \mathbf{b}$，$h_i = a_i b_i$。对 $\mathbf{a}$ 求导，把 $\mathbf{b}$ 当常数，对角线上是 $b_i$；对 $\mathbf{b}$ 求导同理：

$$\frac{\partial (\mathbf{a} \otimes \mathbf{b})}{\partial \mathbf{a}} = \mathrm{diag}(\mathbf{b}),\qquad \frac{\partial (\mathbf{a} \otimes \mathbf{b})}{\partial \mathbf{b}} = \mathrm{diag}(\mathbf{a})$$

残差相加 $\mathbf{y} = \mathbf{x} + \mathbf{h}$ 是最简单的一种，对角线上全是 $1$，Jacobian 是单位矩阵 $I$。attention 分数除以 $\sqrt{d_h}$ 是乘常数，Jacobian 是 $\dfrac{1}{\sqrt{d_h}} I$。

softmax 不是逐元素运算。它的每个输出 $p_j = e^{s_j} / \sum_k e^{s_k}$ 的分母含全部 $s_k$，每个输出依赖全部输入，Jacobian 不是对角矩阵，后文 softmax 一节单独计算。

求和与平均

损失是 $T$ 个位置各自的损失取平均：$L = \dfrac{1}{T}\sum_{t=1}^{T} \ell_t$。这是一个输入为向量、输出为标量的运算，导数是一个梯度，第 $t$ 个分量是 $L$ 对 $\ell_t$ 的偏导数：

$$\frac{\partial L}{\partial \ell_t} = \frac{1}{T},\qquad \frac{\partial L}{\partial \mathbf{\ell}} = \Big[\frac{1}{T}\ \ \frac{1}{T}\ \cdots\ \frac{1}{T}\Big]$$

直接求和不取平均时，每个分量是 $1$。softmax 的分母 $\sum_k e^{s_k}$ 也是求和，但每一项在求和之前先经过了指数函数，对它求导要用链式法则。

链式法则

到目前为止，每条规则只处理一个运算。模型里的运算是嵌套的：$\mathrm{Swish}(\mathbf{x}W_{gate})$ 先做矩阵乘法，再对结果做 Swish；损失函数又套在整个模型外面。我们使用链式法则来求嵌套函数的导数。

单变量链式法则

取 FFN gate 分支的一个分量：$a = x\,w$，$h = \mathrm{Swish}(a)$。我们要计算 $\dfrac{dh}{dx}$。$h$ 由 $a$ 算出，$a$ 由 $x$ 算出，所以 $h$ 通过中间变量 $a$ 依赖 $x$，已有的规则没有覆盖这种嵌套。我们已经知道 $a$ 对 $x$ 的导数是 $w$，也知道 $h$ 对 $a$ 的导数是 $\mathrm{Swish}'(a)$，剩下的问题是怎么由这两个导数得到 $h$ 对 $x$ 的导数。

$x$ 变化 $dx$ 时，$a$ 变化 $da = w\,dx$；$a$ 变化 $da$ 时，$h$ 变化 $dh = \mathrm{Swish}'(a)\,da$。把 $da = w\,dx$ 代入 $dh = \mathrm{Swish}'(a)\,da$：

$$dh = \mathrm{Swish}'(a)\cdot w\,dx,\qquad\text{也就是}\qquad \frac{dh}{dx} = \frac{dh}{da}\,\frac{da}{dx}$$

这是单变量链式法则：外层函数的导数乘内层函数的导数，中间变量 $a$ 在两个分式里各出现一次。推导时写出中间变量，比写成 $f'(g(x))\,g'(x)$ 更不容易混淆求导对象。

嵌套更多层时形式相同。$L$ 依赖 $p$，$p$ 依赖 $s$，$s$ 依赖 $w$，则 $\dfrac{dL}{dw} = \dfrac{dL}{dp}\dfrac{dp}{ds}\dfrac{ds}{dw}$，即从最外层的 $L$ 开始逐层向内相乘。

多条路径

上面的情形里 $x$ 只通过 $a$ 影响 $h$，只有一条路径。残差连接 $y = x + g(x)$ 有两条：一条直接到 $y$，一条经过 $g$。

$x$ 变化时，两条路径各产生一份变化，$y$ 的变化量是两份之和，所以导数等于各条路径的贡献之和。直接一条的贡献是 $1 \cdot dx$，经过 $g$ 的一条是 $g'(x)\,dx$：

$$\frac{dy}{dx} = 1 + g'(x)$$

一般情形下，$x$ 通过中间量 $u_1, u_2, \ldots$ 影响 $y$ 时

$$\frac{dy}{dx} = \sum_k \frac{\partial y}{\partial u_k}\,\frac{du_k}{dx}$$

每条路径内部用一次外层乘内层，路径之间求和。上一章 $df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy$ 的加号来自同一条规则。

模型里有三处多条路径。残差连接：每一层的输入既直接进入输出，又经过子层。GQA 共用的 K、V 权重：一组 $W_K$ 被 $n_h / n_{kv}$ 个 query head 使用，损失对它的导数是各 head 传回的梯度之和。Embedding：同一个 token 在序列里出现多次时，$E$ 的对应行被使用多次，导数是各次之和。

向量链式法则

把前两个版本合起来，得到向量版本。设 $\mathbf{a} = \mathbf{x}W$，其中 $\mathbf{x} \in \mathbb{R}^{d}$，$\mathbf{a} \in \mathbb{R}^{d_{ff}}$；$\mathbf{h} = \mathrm{Swish}(\mathbf{a}) \in \mathbb{R}^{d_{ff}}$。我们要计算 $\dfrac{\partial \mathbf{h}}{\partial \mathbf{x}}$，即 $d_{ff} \times d$ 个偏导数 $\dfrac{\partial h_j}{\partial x_i}$。

$x_i$ 经由 $a_1, a_2, \ldots, a_{d_{ff}}$ 影响 $h_j$，属于多条路径的情形，每条路径上外层乘内层，再求和：

$$\frac{\partial h_j}{\partial x_i} = \sum_k \frac{\partial h_j}{\partial a_k}\,\frac{\partial a_k}{\partial x_i}$$

右边对 $k$ 求和的形式正是矩阵乘法的定义：第一个矩阵的第 $j$ 行与第二个矩阵的第 $i$ 列的点积。所以整个 Jacobian 是两个 Jacobian 的乘积：

$$\frac{\partial \mathbf{h}}{\partial \mathbf{x}} = \frac{\partial \mathbf{h}}{\partial \mathbf{a}}\,\frac{\partial \mathbf{a}}{\partial \mathbf{x}} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)\; W^{T}$$

形状检查：$d_{ff} \times d_{ff}$ 乘 $d_{ff} \times d$ 得到 $d_{ff} \times d$，对应 $d_{ff}$ 个输出和 $d$ 个输入。

这是向量链式法则：外层的 Jacobian 乘内层的 Jacobian，相乘顺序与单变量版本相同。多条路径的求和包含在矩阵乘法内部。

vector-Jacobian product

按上面的写法，损失对 $W_{gate}$ 的导数要先算出 $\dfrac{\partial \mathbf{a}}{\partial W_{gate}}$，其中 $\mathbf{a} = \mathbf{x}W_{gate} \in \mathbb{R}^{d_{ff}}$。这是形状表中的三维数组，共 $d_{ff} \times d \times d_{ff}$ 个数。取 Llama 2 7B 的 $d_{ff} = 11008$、$d = 4096$，这个数组约有 $5 \times 10^{11}$ 个元素，约为该模型全部参数量的七十倍，放不进显存。

不需要构造它的原因是，我们最终需要的是 $\dfrac{\partial L}{\partial(\cdot)}$，而 $L$ 是标量。先看损失对 $\mathbf{a}$ 的导数：$a_k$ 经由 $h_1, h_2, \ldots$ 影响 $L$，按多条路径求和：

$$\frac{\partial L}{\partial a_k} = \sum_j \frac{\partial L}{\partial h_j}\,\frac{\partial h_j}{\partial a_k} = \sum_j \frac{\partial L}{\partial h_j}\,J_{jk}$$

把 $\dfrac{\partial L}{\partial \mathbf{h}}$ 看成一个行向量 $\mathbf{g} \in \mathbb{R}^{d_{ff}}$，上式就是行向量乘矩阵：

$$\frac{\partial L}{\partial \mathbf{a}} = \mathbf{g}\,J,\qquad \mathbf{g} = \frac{\partial L}{\partial \mathbf{h}}$$

结果仍是行向量，与 $\mathbf{a}$ 同形状。这个运算称为 vector-Jacobian product。反向传播每经过一个运算做的就是它：取损失对该运算输出的导数 $\mathbf{g}$，算出损失对输入的导数 $\mathbf{g}J$，向前一层传递。

计算 $\mathbf{g}J$ 也不需要构造 $J$。模型里有两种 Jacobian：

对角 Jacobian。$J = \mathrm{diag}(\mathbf{v})$ 时，$\mathbf{g}J$ 的第 $k$ 个分量是 $g_k v_k$，也就是逐元素相乘：

$$\mathbf{g}\,\mathrm{diag}(\mathbf{v}) = \mathbf{g} \otimes \mathbf{v}$$

Swish 的反向是 $\mathbf{g} \otimes \mathrm{Swish}'(\mathbf{a})$，一次 $d_{ff}$ 个元素的逐元素乘，而不是一次 $d_{ff} \times d_{ff}$ 的矩阵乘。

矩阵乘法的 Jacobian。$\mathbf{a} = \mathbf{x}W$ 时 $J = W^T$，于是

$$\frac{\partial L}{\partial \mathbf{x}} = \mathbf{g}\,W^{T}$$

这是一次普通的矩阵乘法。损失对 $W$ 的导数同样不需要三维数组：$W_{ki}$ 只出现在 $a_i = \sum_k x_k W_{ki}$ 一个输出里，只有一条路径，

$$\frac{\partial L}{\partial W_{ki}} = \frac{\partial L}{\partial a_i}\,\frac{\partial a_i}{\partial W_{ki}} = g_i\,x_k,\qquad\text{合起来}\qquad \frac{\partial L}{\partial W} = \mathbf{x}^{T}\mathbf{g}$$

$\mathbf{x}^T$ 是 $d \times 1$，$\mathbf{g}$ 是 $1 \times d_{ff}$，乘出来 $d \times d_{ff}$，和 $W$ 同形状。序列有 $T$ 个位置时，$X$ 是 $T \times d$，$G$ 是 $T \times d_{ff}$，$\dfrac{\partial L}{\partial W} = X^T G$，$T$ 个位置的贡献由矩阵乘法中的求和完成。

自动微分系统为每个算子登记的反向函数，输入是 $\mathbf{g}$，输出是 $\mathbf{g}J$，$J$ 本身不出现在计算里。因此反向传播只做几次与前向同规模的矩阵乘法和逐元素乘，开销不超过前向计算的一个小常数倍，与引言中 cheap gradient principle 的结论一致。

每个算子一条反向规则

每个运算的反向规则都可以写成同一个格式。对图里的每个方框：前向算出 输出 $= f(\text{输入})$；反向的输入是 $G = \dfrac{\partial L}{\partial\,\text{输出}}$，它和输出同形状；返回 $\dfrac{\partial L}{\partial\,\text{输入}}$，和输入同形状；方框里有权重的，再返回 $\dfrac{\partial L}{\partial W}$，和 $W$ 同形状。自动微分系统按这个格式为每种运算登记一条反向规则，backward() 按前向的相反顺序逐条调用。

记号：大写 $X$、$G$ 是 $T$ 个位置堆成的矩阵，$X$ 是 $T \times d$；小写 $\mathbf{x}$ 是其中一行。

矩阵乘法

前向：$Z = XW$，$X$ 是 $T \times d$，$W$ 是 $d \times m$，$Z$ 是 $T \times m$。反向的输入是 $G$（$T \times m$）：

$$\frac{\partial L}{\partial X} = G\,W^{T},\qquad \frac{\partial L}{\partial W} = X^{T}G$$

形状检查$G W^T$：$T \times m$ 乘 $m \times d$ 得 $T \times d$，和 $X$ 相同。$X^T G$：$d \times T$ 乘 $T \times m$ 得 $d \times m$，和 $W$ 相同。

上一章已经对一行推过，$T$ 行堆在一起时，$X^T G$ 把 $T$ 个位置对 $W$ 的贡献加在了一起。这一条覆盖图里所有带权重的方框：$W_Q$、$W_K$、$W_V$、$W_O$、$W_{gate}$、$W_{up}$、$W_{down}$、$W_{out}$。attention 里的 $QK^T$ 和 $PV$ 也是矩阵乘法，只是两边都是 activation，没有权重：对 $S = QK^T$，把 $K^T$ 放在 $W$ 的位置，得到 $\dfrac{\partial L}{\partial Q} = G K$，$\dfrac{\partial L}{\partial K} = G^T Q$。

Embedding

前向：第 $t$ 个位置取出 $E$ 的第 $\text{tok}_t$ 行，$X_0[t] = E[\text{tok}_t]$。这等价于一个 one-hot 矩阵（$T \times V$，每行只有一个 1）乘 $E$，所以它是矩阵乘法的特例。

反向的输入是 $G$（$T \times d$）：$\dfrac{\partial L}{\partial E}$ 从全零的 $V \times d$ 矩阵开始，把 $G$ 的第 $t$ 行加到第 $\text{tok}_t$ 行上。同一个 token 在序列里出现几次，对应行就累加几次。token 编号是整数，不对它求导，反向传播在这里结束。

逐元素运算与残差

以下几条的 Jacobian 都是对角矩阵，反向全部是逐元素乘，不含矩阵乘法。

逐元素函数 $H = \mathrm{Swish}(A)$：$\dfrac{\partial L}{\partial A} = G \otimes \mathrm{Swish}'(A)$。sigmoid、指数和其他逐元素函数同理，换成对应的标量导数。

逐元素乘 $H = A \otimes B$：$\dfrac{\partial L}{\partial A} = G \otimes B$，$\dfrac{\partial L}{\partial B} = G \otimes A$。

残差相加 $Y = X + H$：$\dfrac{\partial L}{\partial H} = G$，$\dfrac{\partial L}{\partial X}$ 中来自这条路径的部分同样等于 $G$。$X$ 还通过子层影响 $Y$，该路径传回的导数与这份 $G$ 相加，最终 $\dfrac{\partial L}{\partial X} = G + (\text{子层传回的})$。实现上先把 $G$ 交给子层算完，再做这次加法。

常数缩放 $S = S' / \sqrt{d_h}$：$\dfrac{\partial L}{\partial S'} = G / \sqrt{d_h}$。causal mask 是把常数 $-\infty$ 加到被遮住的位置，它没有参数，被遮住的位置 softmax 输出为零，导数也为零，反向不需要处理。

softmax

对一行 $\mathbf{s} \in \mathbb{R}^{n}$：$p_j = \dfrac{e^{s_j}}{\sum_k e^{s_k}}$。每个 $p_j$ 依赖全部 $s_i$，Jacobian 不是对角的。用商法则算 $\dfrac{\partial p_j}{\partial s_i}$，分子 $e^{s_j}$ 只在 $i = j$ 时依赖 $s_i$，分母对每个 $s_i$ 的导数是 $e^{s_i}$：

$$\frac{\partial p_j}{\partial s_i} = \frac{[i=j]\,e^{s_j}\sum_k e^{s_k} - e^{s_j}e^{s_i}}{\big(\sum_k e^{s_k}\big)^2} = [i=j]\,p_j - p_j p_i$$

$[i = j]$ 在 $i = j$ 时为 1，否则为 0。整个 Jacobian 是 $\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$，即一个对角矩阵减去一个秩为 1 的矩阵。反向按 $\mathbf{g}J$ 计算：

$$\frac{\partial L}{\partial \mathbf{s}} = \mathbf{g}\,\big(\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T\big) = \mathbf{g} \otimes \mathbf{p} - (\mathbf{g}\cdot\mathbf{p})\,\mathbf{p} = \mathbf{p} \otimes \big(\mathbf{g} - (\mathbf{g}\cdot\mathbf{p})\big)$$

最后一个式子里 $\mathbf{g}\cdot\mathbf{p}$ 是标量，从 $\mathbf{g}$ 的每个分量中减去它。这个 Jacobian 不是对角矩阵，反向仍是一次点积、一次减法、一次逐元素乘，计算量与 $n$ 成正比。attention 对 $T \times T$ 的分数矩阵逐行执行这一步，LM head 之后对 $T \times V$ 的 logits 逐行执行。

cross-entropy

前向：第 $t$ 个位置的损失 $\ell_t = -\ln p_{t,\,y_t}$，$y_t$ 是目标 token；$L = \dfrac{1}{T}\sum_t \ell_t$。

反向：$L$ 对 $p_{t,j}$ 的导数，只有 $j = y_t$ 那一项不为零，用对数规则和 $1/T$：

$$\frac{\partial L}{\partial p_{t,j}} = \begin{cases} -\dfrac{1}{T\,p_{t,y_t}} & j = y_t \\[6pt] 0 & j \neq y_t \end{cases}$$

把它作为 $\mathbf{g}$ 代入 softmax 的反向规则。$\mathbf{g}$ 只有一个非零分量，所以 $\mathbf{g}\cdot\mathbf{p} = -\dfrac{1}{T}$，于是 $\mathbf{p} \otimes (\mathbf{g} - (\mathbf{g}\cdot\mathbf{p}))$ 的第 $j$ 个分量是 $p_{t,j}\big(g_j + \frac{1}{T}\big)$。$j = y_t$ 时是 $\frac{1}{T}(p_{t,y_t} - 1)$，其余是 $\frac{1}{T}p_{t,j}$。合起来：

$$\frac{\partial L}{\partial \mathbf{s}_t} = \frac{1}{T}\big(\mathbf{p}_t - \mathbf{y}_t\big),\qquad \frac{\partial L}{\partial S} = \frac{1}{T}\,(P - Y)$$

$\mathbf{y}_t$ 是目标 token 的 one-hot 向量，$Y$ 是它们堆成的 $T \times V$ 矩阵。损失对 logits 的导数等于预测分布减去目标分布。实现中 softmax 和 cross-entropy 通常合成一个算子（PyTorch 的 F.cross_entropy），原因有两个：合并后的反向规则只需一次减法，不必先算出 $-1/p$ 再代回 softmax 的反向；前向按 $\ln p_j = s_j - \ln\sum_k e^{s_k}$ 计算，配合减去每行最大值，避免 $e^{s_j}$ 溢出和 $p_j$ 下溢后取对数。

GQA attention

attention 是上面几条规则的组合，没有新规则。对一个 query head $i$，设它所在的组是 $j$，前向依次是：

  1. 三次矩阵乘法：$Q_i = XW_Q^{(i)}$，$K_j = XW_K^{(j)}$，$V_j = XW_V^{(j)}$。
  2. 矩阵乘法加常数缩放加 mask：$S_i = Q_iK_j^T/\sqrt{d_h} + M$。
  3. 逐行 softmax：$P_i = \mathrm{softmax}(S_i)$。
  4. 矩阵乘法：$A_i = P_iV_j$。
  5. 拼接所有 head，矩阵乘法：$A = [A_1 \cdots A_{n_h}]\,W_O$。

反向按相反顺序：$W_O$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial W_O}$，并把 $G$ 拆回每个 head 的 $\dfrac{\partial L}{\partial A_i}$；$A_i = P_iV_j$ 给出 $\dfrac{\partial L}{\partial P_i}$ 和 $V_j$ 的一份梯度；softmax 的反向给出 $\dfrac{\partial L}{\partial S_i}$；除以 $\sqrt{d_h}$；$S_i$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial Q_i}$ 和 $K_j$ 的一份梯度。

需要相加的地方有两处。第一，$K_j$ 和 $V_j$ 被同一组的 $n_h / n_{kv}$ 个 head 共用，每个 head 各传回一份梯度，$\dfrac{\partial L}{\partial K_j}$ 是这些梯度之和，之后才用矩阵乘法规则得到 $\dfrac{\partial L}{\partial W_K^{(j)}} = X^T\dfrac{\partial L}{\partial K_j}$。第二，$X$ 同时进入了 $Q$、$K$、$V$ 三次矩阵乘法，$\dfrac{\partial L}{\partial X}$ 是这三条路径的梯度之和，再加上残差传回的一份。

FP32 到 BF16 的转换

前向：$W_{\text{bf16}} = \mathrm{round}(W_{\text{fp32}})$，把每个数舍入到 BF16 能表示的最近的值。这一步在图里的每个带权重的方框内部，矩阵乘法之前。

这个函数是阶梯函数：在几乎所有点导数为零，在跳变点不可导。按定义求导会使梯度在这里变为零，权重无法更新。所以框架不按定义求导，而是登记一条约定：

$$\frac{\partial L}{\partial W_{\text{fp32}}} := \frac{\partial L}{\partial W_{\text{bf16}}}\ \text{转回 FP32}$$

也就是把舍入当作恒等运算，导数原样通过。前向用不可导的舍入，反向用恒等函数替代它的导数，这种做法称为 straight-through estimator，Bengio 等人在 2013 年的论文中对它做了系统的讨论[4]。这样得到的梯度是在舍入后的 BF16 权重处算出的，却被当作 FP32 权重处的梯度使用，两者的差别与舍入误差同量级，训练中不对这部分误差做修正。

算出梯度之后，更新也不能直接加在 BF16 权重上。单步更新 $\eta\,\partial L/\partial w$ 相对权重自身的幅度，往往小于 BF16 相邻可表示数的相对间隔（BF16 存储 7 位尾数，相对间隔约 $2^{-7}$），加上去之后会被舍入丢掉。这个问题来自 BF16 的精度，与 straight-through estimator 无关。Micikevicius 等人在 2018 年的混合精度训练论文里针对 FP16 说明了这个问题[3]，解决办法是保留一份 FP32 主权重：更新累加在 FP32 上，每一步前向再舍入成 BF16。activation 一侧同理，矩阵乘法在 BF16 中进行，反向传回的 $G$ 是 BF16，$X^T G$ 得到的权重导数累加到 FP32。

整个模型的反向传播

反向传播从 $L$ 出发，沿图中箭头的反方向进行，每经过一个方框调用对应的规则，每到一个圆角框把各条路径传回的导数相加。下面按步骤列出整个过程，图上高亮的是当前位置。
