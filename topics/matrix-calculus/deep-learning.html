引言

训练一个模型，就是反复调整参数使损失变小。优化器每更新一次参数，都需要先知道损失对每个参数的导数：这个参数增大时，损失增大还是减小，变化多快。

单变量微积分里，导数描述的是一个数的变化引起另一个数变化多少。损失对一个参数的导数也是这个意思：参数是一个标量（一个数），损失是一个标量。但模型里的参数以矩阵的形式存放，每一层的输出是向量或矩阵，我们要一次算出损失对整个矩阵的导数，中间还要经过向量对向量的导数。把导数的定义从标量对标量扩展到标量对矩阵、向量对向量，这部分内容称为矩阵微积分。

PyTorch 这样的框架用 loss.backward() 完成全部求导，不需要手写推导。它使用的方法是反向模式自动微分。这个方法有一个基本结论：算出损失对全部参数的导数，开销不超过一次前向计算的几倍，与参数的个数无关，Griewank 和 Walther 称之为 cheap gradient principle[2]。由于这个结论，反向传播可以用于有几十亿个参数的模型。本文说明这个结论是怎么来的：沿一个 decoder-only Transformer 的计算图，给出 backward 在每一步用到的求导规则，以及这些规则合起来为什么不需要构造比数据更大的中间量。

本文假定读者了解 Transformer 的各个模块，用 PyTorch 训练过模型，微积分已经生疏。

什么是 RMSNorm

RMSNorm 对每个位置的向量 $\mathbf{x} \in \mathbb{R}^{d}$ 单独计算：先除以 $\mathbf{x}$ 的均方根，再逐元素乘一个可学习的权重 $\gamma \in \mathbb{R}^{d}$[5]：

$$\mathrm{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\mathrm{rms}(\mathbf{x})} \otimes \gamma \in \mathbb{R}^{d},\qquad \mathrm{rms}(\mathbf{x}) = \sqrt{\frac{1}{d}\sum_{k=1}^{d} x_k^2 + \epsilon}$$

$\epsilon$ 是一个很小的正数（例如 $10^{-6}$），防止分母为零。除以 $\mathrm{rms}(\mathbf{x})$ 之后，各分量平方的平均值约等于 1，与输入向量本身的大小无关。和 LayerNorm 相比，RMSNorm 不减去均值，也没有偏置项。

什么是 SwiGLU FFN

FFN 对序列里的每个位置独立计算，所以下面只写一个位置的向量 $\mathbf{x} \in \mathbb{R}^{d}$：

$$\mathbf{h} = \big(\mathrm{Swish}(\mathbf{x}W_{gate}) \otimes \mathbf{x}W_{up}\big)\,W_{down}$$

三个权重矩阵是 $W_{gate}, W_{up} \in \mathbb{R}^{d \times d_{ff}}$ 和 $W_{down} \in \mathbb{R}^{d_{ff} \times d}$。$\otimes$ 表示逐元素相乘。Swish 逐元素作用在向量上，对每个数做的是 $\mathrm{Swish}(z) = z\,\sigma(z)$，其中 $\sigma(z) = \dfrac{1}{1+e^{-z}}$ 是 sigmoid 函数。

什么是 GQA Attention

Attention 让每个位置读取它自己和前面所有位置的信息。输入 $X \in \mathbb{R}^{T \times d}$，每一行是一个位置的向量。在本文的模型里，$X$ 是 RMSNorm 的输出。

先看一个 head。$X$ 分别乘三个权重矩阵 $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_h}$，得到 query、key、value 三个矩阵 $Q, K, V \in \mathbb{R}^{T \times d_h}$，每一行对应一个位置：

$$Q = XW_Q,\qquad K = XW_K,\qquad V = XW_V$$

然后计算

$$A = \mathrm{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_h}} + M\right) V$$

$QK^T \in \mathbb{R}^{T \times T}$，第 $t$ 行第 $s$ 列是位置 $t$ 的 query 与位置 $s$ 的 key 的点积，称为 attention 分数。$M$ 是 causal mask，把 $t < s$ 的元素置为 $-\infty$，使位置 $t$ 只读取自己和前面的位置。softmax 对每一行独立作用，把一行分数变成一组和为 1 的权重。最后乘 $V$：$A$ 的第 $t$ 行是各位置 value 向量按这组权重的加权和，$A \in \mathbb{R}^{T \times d_h}$。

Multi-Head Attention（MHA）把这个计算并行做 $n_h$ 次，每个 head 有自己的 $W_{Qi}$、$W_{Ki}$、$W_{Vi}$。$n_h$ 个 head 的输出 $A_1, \ldots, A_{n_h}$ 按列拼接成 $T \times n_h d_h$ 的矩阵，再乘 $W_O \in \mathbb{R}^{n_h d_h \times d}$，回到 $\mathbb{R}^{T \times d}$。

Grouped-Query Attention（GQA）相比 MHA 只改变 key 和 value 的数量：query 仍有 $n_h$ 个 head，key 和 value 只有 $n_{kv}$ 组，每组被 $n_h / n_{kv}$ 个 query head 共用。下图是 $n_h = 4$ 时 MHA 与 GQA 的对比，右边的 GQA 取 $n_{kv} = 2$。

用下标写出来：query head $i$ 属于第 $j$ 组时，

$$Q_i = XW_Q^{(i)},\qquad K_j = XW_K^{(j)},\qquad V_j = XW_V^{(j)}$$ $$A_i = \mathrm{softmax}\!\left(\frac{Q_iK_j^{T}}{\sqrt{d_h}} + M\right) V_j$$

这样做是为了减小推理时的 KV cache：生成每个新 token 时，前面所有位置的 $K$、$V$ 都要保存下来，组数从 $n_h$ 减到 $n_{kv}$，这部分显存按同样的比例减小。例如 Llama 2 70B 有 64 个 query head，8 组 K/V。

本文的模型在计算 attention 分数之前，还对 query 和 key 各做两步处理。

第一步是 QK-Norm：对 $Q_i$ 和 $K_j$ 的每一行做 RMSNorm，归一化的维度是 $d_h$。query 和 key 各有一个权重 $\gamma_q, \gamma_k \in \mathbb{R}^{d_h}$，同一层的所有 head 共用这两个权重。这一步限制了 attention 分数的大小，使训练更稳定。

第二步是 RoPE：把 $Q_i$ 和 $K_j$ 的每一行按它所在的位置旋转，使 attention 分数依赖两个位置的差。定义见下面「什么是 RoPE」折叠块。

加上这两步，query head $i$ 的完整计算是

$$\tilde{Q}_i = \mathrm{RoPE}\big(\mathrm{RMSNorm}(XW_Q^{(i)})\big),\qquad \tilde{K}_j = \mathrm{RoPE}\big(\mathrm{RMSNorm}(XW_K^{(j)})\big),\qquad V_j = XW_V^{(j)}$$ $$A_i = \mathrm{softmax}\!\left(\frac{\tilde{Q}_i\tilde{K}_j^{T}}{\sqrt{d_h}} + M\right) V_j$$

下图画出了这个计算过程，再加上最后的拼接和 $W_O$。图中只画了 query head $i$ 一个 head；第 $j$ 组的 $\tilde{K}_j$ 和 $V_j$ 还要被同组的其他 head 使用，$\mathrm{Concat}$ 把 $n_h$ 个 head 的输出按列拼接起来。

什么是 RoPE

attention 分数是 query 与 key 的点积，点积只由两个向量的值决定，不包含它们在序列里的位置。RoPE（rotary position embedding）在计算点积之前，按位置旋转 query 和 key，使点积依赖两个位置的差[6]。

两维的情形。先设 $d_h = 2$。位置 $t$ 的 query 向量 $\mathbf{q} = [\,q_1\ \ q_2\,]$ 看作平面上的一个点，RoPE 把它绕原点逆时针旋转角度 $t\theta$：

$$\mathrm{RoPE}(\mathbf{q}) = \mathbf{q}\,R(t\theta),\qquad R(\alpha) = \begin{bmatrix}\cos\alpha & \sin\alpha\\ -\sin\alpha & \cos\alpha\end{bmatrix}$$

$\theta$ 是一个固定的角度，位置每增加 1，向量多转 $\theta$。位置 $s$ 的 key 向量 $\mathbf{k}$ 同样旋转 $s\theta$。旋转矩阵满足 $R(\alpha)R(\beta)^{T} = R(\alpha - \beta)$，所以旋转之后的点积是

$$\big(\mathbf{q}R(t\theta)\big)\big(\mathbf{k}R(s\theta)\big)^{T} = \mathbf{q}\,R(t\theta)R(s\theta)^{T}\,\mathbf{k}^{T} = \mathbf{q}\,R\big((t-s)\theta\big)\,\mathbf{k}^{T}$$

结果只依赖位置差 $t - s$。几何上，两个向量的长度不变，夹角改变 $(t-s)\theta$，所以两个位置同时增加相同的数时，点积不变。

$d_h$ 维的情形。把 $d_h$ 个分量按顺序分成 $d_h/2$ 对，第 $k$ 对 $(q_{2k-1}, q_{2k})$ 在自己的平面里旋转角度 $t\theta_k$，其中

$$\theta_k = b^{-2(k-1)/d_h},\qquad k = 1, \ldots, d_h/2$$

$b$ 是一个常数，原论文取 $10000$，Llama 3 取 $500000$。$\theta_1 = 1$，之后逐对减小，最后一对接近 $1/b$：前几对随位置转得快，后几对转得慢。各对之间互不影响，合起来是一个分块对角的 $d_h \times d_h$ 正交矩阵 $R_t$，对角线上是 $d_h/2$ 个 $2 \times 2$ 旋转矩阵：

$$\mathrm{RoPE}(\mathbf{q}_t) = \mathbf{q}_t R_t \in \mathbb{R}^{d_h},\qquad R_t = \begin{bmatrix} R(t\theta_1) & & \\ & \ddots & \\ & & R(t\theta_{d_h/2}) \end{bmatrix}$$

点积等于各对的点积之和，每一对都满足两维情形的结论，所以

$$(\mathbf{q}_t R_t)(\mathbf{k}_s R_s)^{T} = \mathbf{q}_t\,R_{t-s}\,\mathbf{k}_s^{T}$$

下图画出其中一对分量的旋转，取 $d_h = 8$、$b = 10000$，四对的 $\theta_k$ 分别是 $1$、$0.1$、$0.01$、$0.001$。虚线是旋转前的 $\mathbf{q}$ 和 $\mathbf{k}$，实线是旋转后的向量。两个滑块设置 query 的位置 $t$ 和 key 的位置 $s$。点「$t$ 和 $s$ 同时加 1」，两个向量转过相同的角度，旋转后的点积不变。切换到第 4 对，$t = 20$ 时向量只转了 $0.02$ 弧度。

RoPE 没有参数，$R_t$ 由位置 $t$ 完全确定。实现里分量的配对方式不一定是相邻两个：Hugging Face 的 Llama 实现把第 $k$ 个和第 $k + d_h/2$ 个分量配成一对。两种配对只差一个固定的分量重排，上面的结论相同。

深度学习中导数的形状

模型里被求导的量有三种形状：标量、向量、矩阵。输入三种、输出三种，一共九种组合。求导的结果要放下每个输出分量对每个输入分量的导数，所以输出有 $m$ 个分量、输入有 $n$ 个分量时，结果有 $m \times n$ 个数。

下表列出九种组合和每一种结果的形状。其中标量对向量的导数称为梯度，向量对向量的导数称为 Jacobian。这里先给出结果，标量的导数和偏导数的定义分别在标量的导数和向量微积分与偏导数入门两章给出。

$y \in \mathbb{R}$ $$\frac{dy}{dx} \in \mathbb{R}$$ $$\frac{\partial y}{\partial \mathbf{x}} = \Big[\frac{\partial y}{\partial x_1}\ \ \cdots\ \ \frac{\partial y}{\partial x_n}\Big] \in \mathbb{R}^{n}$$ $$\frac{\partial y}{\partial W} = \begin{bmatrix} \frac{\partial y}{\partial W_{11}} & \cdots & \frac{\partial y}{\partial W_{1q}}\\ \vdots & & \vdots\\ \frac{\partial y}{\partial W_{p1}} & \cdots & \frac{\partial y}{\partial W_{pq}} \end{bmatrix} \in \mathbb{R}^{p \times q}$$

训练最终需要的结果全在第一行。损失是标量，所以损失对任何变量的导数都与该变量同形状：$x \in \mathbb{R}$ 时 $\frac{\partial L}{\partial x} \in \mathbb{R}$，$\mathbf{x} \in \mathbb{R}^{n}$ 时 $\frac{\partial L}{\partial \mathbf{x}} \in \mathbb{R}^{n}$，$W \in \mathbb{R}^{p \times q}$ 时 $\frac{\partial L}{\partial W} \in \mathbb{R}^{p \times q}$。这就是为什么 PyTorch 里 w.grad 的形状总是与 w 相同。

表中三维和四维数组的三个灰格（向量-矩阵、矩阵-向量、矩阵-矩阵）只出现在中间步骤。损失对 $W_{down}$ 的导数，按链式法则要经过损失对 $\mathbf{h}$ 的导数和 $\mathbf{h}$ 对 $W_{down}$ 的导数两步，后一步就是第二行最后一格的三维数组。反向传播不构造这个数组，而是直接算出两步合并后的结果，vector-Jacobian product 一节说明怎么做。

本文写向量对向量的导数时，行对应输出，列对应输入，上表 Jacobian 一格就是这样排的，这种排法称为 numerator layout。有些资料采用转置的排法，称为 denominator layout。别处的公式形状与本文不一致时，先检查这一点。

标量的导数

对向量和矩阵求导，最后一步都会归结到是对单个数求导，我们先复习标量的导数：导数的定义，以及常见的求导规则。

什么是导数

先看最简单的情形：一个输入 $x$，一个输出 $y = f(x)$，两者都是标量。

$x$ 变到 $x + \Delta x$ 时，$y$ 的变化量与 $x$ 的变化量之比是 $\dfrac{\Delta y}{\Delta x} = \dfrac{f(x+\Delta x) - f(x)}{\Delta x}$。$\Delta x$ 趋于零时这个比值的极限，就是 $y$ 对 $x$ 的导数，记作 $\dfrac{dy}{dx}$：

$$\frac{dy}{dx} = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x}$$

$\dfrac{dy}{dx}$ 是一个整体记号，分子是被求导的量，分母是自变量。同一个导数也写成 $\dfrac{df}{dx}$ 或 $\dfrac{d}{dx}f(x)$。几何上，$\dfrac{dy}{dx}$ 是 $f$ 的图像在 $x$ 处的切线的斜率。

割线、切线与导数的图像

比值 $\dfrac{\Delta y}{\Delta x}$ 是 $f$ 的图像上过 $x$ 和 $x+\Delta x$ 两点的直线的斜率，这条直线称为割线。

这个比值随 $\Delta x$ 改变。取 $f(x) = x^3$，在 $x = 1$ 处：$\Delta x = 1$ 时比值是 $7$，$\Delta x = 0.1$ 时是 $3.31$，$\Delta x = 0.01$ 时是 $3.0301$。$\Delta x$ 越小，比值越接近 $3$。下图的两个滑块分别控制 $x_0$ 和 $\Delta x$，把 $\Delta x$ 从 $1$ 减小到 $0.001$，可以看到割线的斜率逐渐接近 $3$。

$\Delta x$ 趋于零时，割线趋于一条确定的直线，这条直线是 $x_0$ 处的切线。切线的斜率不再依赖 $\Delta x$，这个斜率就是 $x_0$ 处的导数 $\dfrac{dy}{dx}$。

$x_0$ 取不同位置时切线的斜率不同，所以导数 $\dfrac{dy}{dx}$ 本身也是 $x$ 的函数，图的下半部分画的是它。对 $y = x^3$ 有 $\dfrac{dy}{dx} = 3x^2$，对 $y = \sin x$ 有 $\dfrac{dy}{dx} = \cos x$。

记号 $\dfrac{dy}{dx}$ 里的 $d$ 表示无穷小的变化量：把比值 $\dfrac{\Delta y}{\Delta x}$ 中的 $\Delta$ 换成 $d$，表示 $\Delta x$ 趋于零之后的结果。

导数可以用来估计输出的变化量。$\Delta x$ 很小时，比值 $\dfrac{\Delta y}{\Delta x}$ 接近它的极限 $\dfrac{dy}{dx}$，两边乘 $\Delta x$ 得到

$$\Delta y \approx \frac{dy}{dx}\,\Delta x$$

也就是说，输入变化 $\Delta x$ 时，输出的变化量约为 $\dfrac{dy}{dx}$ 与 $\Delta x$ 的乘积，$\Delta x$ 越小，近似越准确。后文讲多个输入同时变化和函数嵌套时，都从这个式子出发。

$\dfrac{d}{dx}$ 是一个运算符，输入一个函数，输出另一个函数。它对加法可以拆开，常数因子可以提到它前面，所以对复杂表达式求导可以先拆分、分别求导、再组合：

$$\frac{d}{dx}\,9(x + x^2) = 9\,\frac{d}{dx}(x + x^2) = 9\Big(\frac{d}{dx}x + \frac{d}{dx}x^2\Big) = 9(1 + 2x) = 9 + 18x$$

后面对向量和矩阵求导用的也是这个做法：把表达式拆成已有规则覆盖的部分，分别求导，再按形状组合。

举例：Sigmoid 与 Swish 的导数

sigmoid 可以写成复合函数：$\sigma(x) = u^{-1}$，其中 $u = 1 + e^{-x}$。外层按幂函数求导；内层按加法求导，其中 $e^{-x}$ 按指数函数和链式法则求导：

$$\frac{d\sigma}{du} = -u^{-2},\qquad \frac{du}{dx} = -e^{-x}$$

按链式法则把两者相乘：

$$ \begin{aligned} \frac{d\sigma}{dx} = \frac{d\sigma}{du}\,\frac{du}{dx} &= \frac{e^{-x}}{(1+e^{-x})^2}\\ &= \frac{1}{1+e^{-x}} \cdot \frac{e^{-x}}{1+e^{-x}}\\ &= \sigma(x)\,\big(1-\sigma(x)\big) \end{aligned} $$

Swish 是两个函数的乘积：$\mathrm{Swish}(x) = x \cdot \sigma(x)$。按乘积法则，再代入上面的 $\dfrac{d\sigma}{dx}$：

$$\frac{d\,\mathrm{Swish}(x)}{dx} = 1 \cdot \sigma(x) + x\,\frac{d\sigma}{dx} = \sigma(x) + x\,\sigma(x)\,\big(1-\sigma(x)\big) = \sigma(x)\,\big(1 + x\,(1-\sigma(x))\big)$$

在「什么是导数」一节折叠块的图里选 $\mathrm{Swish}(x)$，可以对照切线斜率和这个式子的取值。

后文会把 Swish 逐元素作用在向量和矩阵上，反向传播要在每个元素处计算上面这个导数。为了书写方便，把它记作一个函数：

$$\mathrm{Swish}'(x) = \frac{d\,\mathrm{Swish}(x)}{dx} = \sigma(x)\,\big(1 + x\,(1-\sigma(x))\big)$$

$\mathrm{Swish}'$ 和 $\mathrm{Swish}$ 一样，是只有一个输入的标量函数，撇号表示对这个唯一的输入求导。它作用在向量或矩阵上时，对每个元素分别计算，结果与输入同形状，例如 $\mathrm{Swish}'(\mathbf{a}) = [\,\mathrm{Swish}'(a_1)\ \ \mathrm{Swish}'(a_2)\ \ \cdots\,]$。本文对其他逐元素函数 $f$ 的导数也这样记作 $f'$。

向量微积分与偏导数入门

上一章的函数只有一个输入，而模型里的函数都有多个输入。例如 LM head 的第 $j$ 个 logit

$$z_j = \sum_{k=1}^{d} x_k W_{kj} = \mathbf{x}\,W_{:,j}$$

其中 $\mathbf{x} = [\,x_1\ \ x_2\ \ \cdots\ \ x_d\,]$ 是输入的行向量，$W_{:,j} = [\,W_{1j}\ \ W_{2j}\ \ \cdots\ \ W_{dj}\,]^{T}$ 是 $W$ 的第 $j$ 列，即 PyTorch 里的 W[:, j]。$z_j$ 依赖 $d$ 个输入 $x_k$ 和 $d$ 个权重 $W_{kj}$。我们需要梳理清楚：对其中一个求导时，其他输入怎么处理。

偏导数

$f(x, y) = 3x^2 y$ 有两个输入，变化可以沿 $x$，也可以沿 $y$。我们先只让一个输入变化。

固定 $y$，只让 $x$ 变化，$f$ 就是 $x$ 的单变量函数，上一章的方法可以直接用：它的图像在 $x$ 处的切线斜率，就是 $x$ 变化时 $f$ 的变化率。这个斜率称为 $f$ 对 $x$ 的偏导数，记作 $\dfrac{\partial f}{\partial x}$。计算时把 $y$ 当作常数：

$$\frac{\partial}{\partial x}\,3x^2y = 3y \cdot \frac{d}{dx}x^2 = 3y \cdot 2x = 6xy$$

固定 $x$，只让 $y$ 变化，得到 $f$ 对 $y$ 的偏导数：

$$\frac{\partial}{\partial y}\,3x^2y = 3x^2 \cdot \frac{d}{dy}y = 3x^2$$

符号 $\partial$ 和 $d$ 的区别是：$\partial$ 表示函数还有其他输入，求导时它们保持不变。对只有一个输入的函数，$\dfrac{\partial f}{\partial x}$ 与 $\dfrac{df}{dx}$ 相同。

下图左边是 $f(x, y)$ 的取值，黑点是选定的位置 $(x_0, y_0)$，经过黑点的黑色曲线是 $f$ 的等值线，曲线上每一点的 $f$ 都等于 $f(x_0, y_0)$。右边两张图是过这个点、分别固定 $y = y_0$ 和固定 $x = x_0$ 切出的两条单变量曲线，各带一条切线，两条切线的斜率就是两个偏导数。

左图上从黑点出发的绿色箭头沿 $x$ 方向，长度是 $\dfrac{\partial f}{\partial x}$；粉色箭头沿 $y$ 方向，长度是 $\dfrac{\partial f}{\partial y}$；偏导数为负时箭头朝反方向。紫色箭头是两者合成的向量，也就是我们常说的梯度（见下一节）。

梯度

训练时我们希望一次性更新全部参数（同时变化），所以我们还要知道 $x$ 变化 $\Delta x$、$y$ 同时变化 $\Delta y$ 时，$f$ 变化多少。

$\Delta x$、$\Delta y$ 都很小时，可以把同时变化拆成两步。先只让 $x$ 变化，按上一章的近似，$f$ 变化约 $\dfrac{\partial f}{\partial x}\,\Delta x$；再只让 $y$ 变化，$f$ 再变化约 $\dfrac{\partial f}{\partial y}\,\Delta y$。第二步是在 $x$ 已经变化之后的位置求偏导，但 $\Delta x$ 很小时，那里的偏导数与原位置几乎相同。所以 $f$ 的变化约等于两个偏导数各自的贡献之和：

$$\Delta f \approx \frac{\partial f}{\partial x}\,\Delta x + \frac{\partial f}{\partial y}\,\Delta y$$

$\Delta x$、$\Delta y$ 越小，近似越准确。

把两个输入写成一个向量 $\mathbf{x} = [\,x\ \ y\,]$，它的变化量是 $\Delta\mathbf{x} = [\,\Delta x\ \ \Delta y\,]$。

两个偏导数也排成一个向量：

$$\nabla f = \frac{\partial f}{\partial \mathbf{x}} = \Big[\,\frac{\partial f}{\partial x}\ \ \frac{\partial f}{\partial y}\,\Big] = [\,6xy\ \ 3x^2\,]$$

这个向量称为 $f$ 的梯度，记作 $\nabla f$ 或 $\dfrac{\partial f}{\partial \mathbf{x}}$，$\nabla$ 读作 nabla。上面的近似于是可以写成点积：

$$\Delta f \approx \nabla f \cdot \Delta\mathbf{x}$$

上图的紫色箭头就是 $\nabla f$，它由绿色和粉色两个箭头合成。紫色箭头总是垂直于经过黑点的等值线：沿等值线走一小步 $\Delta\mathbf{x}$，$f$ 不变，所以 $\nabla f \cdot \Delta\mathbf{x} \approx 0$。这个近似的误差随步长缩小得比步长本身更快，所以步长趋于零时，$\nabla f$ 与这一步之间的夹角趋于 $90^\circ$，也就是等值线在黑点处的方向与 $\nabla f$ 垂直。点积等于两个向量的长度之积乘夹角的余弦，所以在长度相同的所有 $\Delta\mathbf{x}$ 中，与 $\nabla f$ 同方向的那个使 $\nabla f \cdot \Delta\mathbf{x}$ 最大，即梯度指向 $f$ 增大最快的方向。

与单变量的 $\Delta y \approx \dfrac{dy}{dx}\,\Delta x$ 对照，导数的位置换成了梯度，乘法换成了点积。输入有 $n$ 个分量时，梯度就是 $n$ 个偏导数排成一行，对应形状表里标量对向量一格。损失 $L$ 的梯度 $\nabla L$ 由损失对每个参数的偏导数组成，优化器沿 $-\nabla L$ 的方向更新参数，每个参数用到的只是自己那一个偏导数 $\dfrac{\partial L}{\partial w}$。

损失对 logits 的梯度

先看模型的最后一段。本节的配图取自开头的模型图，只画序列中的一个位置，高亮的是本节要计算的部分。

LM head 在这个位置输出 $V$ 个 logit $\mathbf{z} = [\,z_1\ \ z_2\ \ \cdots\ \ z_V\,]$，softmax 把它们变成 $V$ 个概率：

$$p_j = \frac{e^{z_j}}{\sum_{k=1}^{V} e^{z_k}}$$

每个 $p_j$ 都在 0 和 1 之间，$V$ 个加起来等于 1，$p_j$ 是模型给词表中第 $j$ 个 token 的概率。设这个位置的目标 token 是第 $y$ 个，cross-entropy 损失是目标 token 的概率取负对数：

$$\ell = -\ln p_y$$

$p_y$ 越接近 1，$\ell$ 越接近 0。训练用的损失 $L$ 是 $T$ 个位置各自的 $\ell$ 取平均，这里只看一个位置。

$\ell$ 是一个标量，依赖全部 $V$ 个 logit，所以它对 $\mathbf{z}$ 的导数是一个梯度，有 $V$ 个分量。先用 $\ln\dfrac{a}{b} = \ln a - \ln b$ 和 $\ln e^{z} = z$ 把 $\ell$ 展开：

$$\ell = -\ln \frac{e^{z_y}}{\sum_k e^{z_k}} = -z_y + \ln \sum_{k=1}^{V} e^{z_k}$$

对 $z_j$ 求偏导时，其余的 logit 都当作常数，两项分别计算。

第一项 $-z_y$：$j = y$ 时，它对 $z_j$ 的导数是 $-1$；$j \neq y$ 时，$-z_y$ 不含 $z_j$，导数是 $0$。

第二项：记 $u = \sum_k e^{z_k}$。其余 logit 固定时，$u$ 是 $z_j$ 的单变量函数，按规则表里的链式法则，$\ln u$ 对 $z_j$ 的导数是 $\dfrac{1}{u}$ 乘 $u$ 对 $z_j$ 的导数。$u$ 的 $V$ 项里只有 $e^{z_j}$ 含 $z_j$，它的导数是 $e^{z_j}$，所以

$$\frac{\partial}{\partial z_j} \ln \sum_k e^{z_k} = \frac{e^{z_j}}{\sum_k e^{z_k}} = p_j$$

两项相加：

$$\frac{\partial \ell}{\partial z_j} = \begin{cases} p_j - 1 & j = y \\ p_j & j \neq y \end{cases}$$

把目标 token 写成一个 one-hot 向量 $\mathbf{y}$：第 $y$ 个分量是 1，其余分量是 0。$V$ 个偏导数排成一行，就是 $\ell$ 对 $\mathbf{z}$ 的梯度：

$$\frac{\partial \ell}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{y},\qquad \mathbf{p} = [\,p_1\ \ p_2\ \ \cdots\ \ p_V\,]$$

例如 $V = 3$，$\mathbf{z} = [\,2\ \ 1\ \ 0\,]$，目标是第 1 个 token。这时 $\mathbf{p} \approx [\,0.665\ \ 0.245\ \ 0.090\,]$，梯度是 $[\,-0.335\ \ 0.245\ \ 0.090\,]$。

梯度的每个分量给出对应的 logit 增大时损失的变化率。

  • 目标 token 的分量是 $p_y - 1 < 0$，它的 logit 增大时损失减小；
  • 其余分量是 $p_j > 0$，这些 logit 增大时损失增大，变化率等于该 token 的概率；
  • $p_y$ 接近 1 时，所有分量都接近 0，损失几乎不再随 logits 变化。

链式法则

规则表的最后一行是链式法则，前面已经用过两次：sigmoid 的导数把 $\sigma(x)$ 写成 $u^{-1}$，其中 $u = 1 + e^{-x}$；损失对 logits 的梯度一节把 $\sum_k e^{z_k}$ 记作 $u$，再对 $\ln u$ 求导。这两处都是输入只经过一个中间变量影响输出。反向传播的下一步是 LM head，那里的情形不同：LM head 的输入 $\mathbf{x}$ 的每个分量都出现在全部 $V$ 个 logit 里，经过 $V$ 个中间变量影响损失。所以我们还需要知道，输入经过多个中间变量影响输出时怎样求导。这要从单变量链式法则为什么成立说起。

单变量链式法则

取 FFN gate 分支的一个分量：$a = x\,w$，$h = \mathrm{Swish}(a)$。$h$ 由 $a$ 算出，$a$ 由 $x$ 算出，所以 $h$ 通过中间变量 $a$ 依赖 $x$。我们已经知道 $a$ 对 $x$ 的导数是 $w$，也知道 $h$ 对 $a$ 的导数是 $\mathrm{Swish}'(a)$。规则表里的链式法则说，$h$ 对 $x$ 的导数是这两个导数的乘积。这个结论可以由「什么是导数」一节的近似式 $\Delta y \approx \dfrac{dy}{dx}\,\Delta x$ 得到。

$x$ 变化 $\Delta x$ 时，$a$ 变化 $\Delta a = w\,\Delta x$；$a$ 变化 $\Delta a$ 时，$h$ 变化约 $\Delta h \approx \mathrm{Swish}'(a)\,\Delta a$。把 $\Delta a = w\,\Delta x$ 代入 $\Delta h \approx \mathrm{Swish}'(a)\,\Delta a$：

$$\Delta h \approx \mathrm{Swish}'(a)\cdot w\,\Delta x$$

$\Delta x$ 越小，近似越准确，所以 $\Delta h$ 与 $\Delta x$ 之比的极限，也就是 $h$ 对 $x$ 的导数，是两个导数的乘积：

$$\frac{dh}{dx} = \mathrm{Swish}'(a)\cdot w = \frac{dh}{da}\,\frac{da}{dx}$$

这是单变量链式法则：外层函数的导数乘内层函数的导数，中间变量 $a$ 在两个分式里各出现一次。写出中间变量，可以看清每个导数是对哪个变量求的。

嵌套更多层时形式相同。$y$ 依赖 $u$，$u$ 依赖 $v$，$v$ 依赖 $x$，则 $\dfrac{dy}{dx} = \dfrac{dy}{du}\dfrac{du}{dv}\dfrac{dv}{dx}$，即从最外层的 $y$ 开始逐层向内相乘。

多条路径

上面的情形里 $x$ 只通过 $a$ 影响 $h$，只有一条路径。残差连接 $y = x + g(x)$ 有两条：一条直接到 $y$，一条经过 $g$。

$x$ 变化 $\Delta x$ 时，两条路径各产生一份变化，$y$ 的变化量是两份之和，所以导数等于各条路径的贡献之和。直接一条的贡献是 $1 \cdot \Delta x$，经过 $g$ 的一条约是 $\dfrac{dg}{dx}\,\Delta x$：

$$\frac{dy}{dx} = 1 + \frac{dg}{dx}$$

一般情形下，$x$ 通过中间变量 $u_1, u_2, \ldots, u_n$ 影响 $y$。$x$ 变化 $\Delta x$ 时，每个 $u_k$ 变化约 $\dfrac{du_k}{dx}\,\Delta x$。$y$ 是 $n$ 个 $u_k$ 的函数，按「梯度」一节的近似，$n$ 个 $u_k$ 同时变化时，$y$ 的变化约等于各自贡献之和：

$$\Delta y \approx \sum_{k=1}^{n} \frac{\partial y}{\partial u_k}\,\Delta u_k \approx \sum_{k=1}^{n} \frac{\partial y}{\partial u_k}\,\frac{du_k}{dx}\,\Delta x$$

所以

$$\frac{dy}{dx} = \sum_{k=1}^{n} \frac{\partial y}{\partial u_k}\,\frac{du_k}{dx}$$

每条路径内部用一次单变量链式法则，外层乘内层，路径之间求和。残差连接是 $n = 2$ 的情形：$u_1 = x$，$u_2 = g(x)$，$y = u_1 + u_2$。$x$ 是多个输入之一时，其余输入保持不变，上式中的 $\dfrac{du_k}{dx}$ 换成偏导数 $\dfrac{\partial u_k}{\partial x}$，形式不变。

模型里的多条路径有两种情形。第一种在一个运算内部：一个输入分量出现在多个输出分量里。例如 LM head 的 $x_i$ 经过全部 $V$ 个 logit 影响损失，下一章用这条规则算出损失对 $\mathbf{x}$ 的导数。第二种是同一个量在计算图里被使用多次。残差连接：每一层的输入既直接进入输出，又经过子层。GQA 共用的 K、V 权重：一组 $W_K$ 被 $n_h / n_{kv}$ 个 query head 使用，损失对它的导数是各 head 传回的梯度之和。Embedding：同一个 token 在序列里出现多次时，$E$ 的对应行被使用多次，导数是各次之和。序列里的 $T$ 个位置：每个位置都使用同一组权重，损失对权重的导数是 $T$ 个位置的贡献之和。

矩阵微积分

「损失对 logits 的梯度」一节算出了一个位置上的 $\dfrac{\partial \ell}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{y}$。反向传播的下一步经过 LM head：它的输入 $\mathbf{x}$ 是向量，权重是矩阵，输出 $\mathbf{z}$ 也是向量。我们要由 $\dfrac{\partial \ell}{\partial \mathbf{z}}$ 算出损失对权重的导数和损失对 $\mathbf{x}$ 的导数。前者用于更新权重。后者用于继续反向传播：$\mathbf{x}$ 由前面各层算出，按链式法则，前面各层参数的导数都要经过损失对 $\mathbf{x}$ 的导数。

LM head 的偏导数

本节配图高亮的是 LM head 和它的输入、输出，左侧标出了已经算出的 $\dfrac{\partial \ell}{\partial \mathbf{z}}$。输入 $\mathbf{x} \in \mathbb{R}^{d}$ 是模型图里 $\hat{X}_N$ 的一行，也就是最后一个 RMSNorm 在这个位置的输出。LM head 计算 $\mathbf{z} = \mathbf{x} W_{out}$，下面把 $W_{out}$ 简写为 $W$，它是 $d \times V$ 的矩阵。第 $j$ 个 logit 是 $\mathbf{x}$ 与 $W$ 第 $j$ 列的点积：

$$z_j = \sum_{k=1}^{d} x_k\,W_{kj} = x_1W_{1j} + x_2W_{2j} + \cdots + x_dW_{dj}$$

两类偏导数。损失对 $W$ 的导数和对 $\mathbf{x}$ 的导数都要经过 logits，所以先求每个 logit 对 $x_i$ 和对 $W_{ij}$ 的偏导数。求 $z_j$ 对 $x_i$ 的偏导数时，$\mathbf{x}$ 的其余分量和全部 $W$ 都当作常数。和式的 $d$ 项里只有 $x_iW_{ij}$ 含 $x_i$，其余各项的导数为 0。对权重 $W_{ij}$ 求偏导的道理相同：

$$\frac{\partial z_j}{\partial x_i} = W_{ij},\qquad \frac{\partial z_j}{\partial W_{ij}} = x_i$$

$W$ 其他列的元素 $W_{im}$（$m \neq j$）不出现在 $z_j$ 的和式里，所以 $\dfrac{\partial z_j}{\partial W_{im}} = 0$。也就是说，$W$ 的第 $j$ 列只影响 $z_j$ 这一个 logit。$x_i$ 则出现在全部 $V$ 个 logit 的和式里，每个 logit 对它的偏导数都可能不为零。

下图取 $d = 2$、$V = 3$，列出两类偏导数的值：

损失对权重的偏导数。$W_{ij}$ 只通过 $z_j$ 影响损失 $\ell$：$W_{ij}$ 变化时，其余 $V - 1$ 个 logit 不变。固定其余参数，$z_j$ 是 $W_{ij}$ 的单变量函数，$\ell$ 是 $z_j$ 的单变量函数，只有一条路径。按单变量链式法则，把 $\dfrac{\partial \ell}{\partial z_j} = p_j - y_j$ 与 $\dfrac{\partial z_j}{\partial W_{ij}}$ 相乘：

$$\frac{\partial \ell}{\partial W_{ij}} = \frac{\partial \ell}{\partial z_j}\,\frac{\partial z_j}{\partial W_{ij}} = (p_j - y_j)\,x_i$$

$y_j$ 是 one-hot 向量 $\mathbf{y}$ 的第 $j$ 个分量。这是本文第一次得到损失对模型参数的导数。

损失对输入的偏导数。$x_i$ 的情形不同，它经过全部 $V$ 个 logit 影响 $\ell$，有 $V$ 条路径。按多条路径的链式法则，每条路径上把 $\dfrac{\partial \ell}{\partial z_j}$ 与 $\dfrac{\partial z_j}{\partial x_i}$ 相乘，再对 $V$ 条路径求和：

$$\frac{\partial \ell}{\partial x_i} = \sum_{j=1}^{V} \frac{\partial \ell}{\partial z_j}\,\frac{\partial z_j}{\partial x_i} = \sum_{j=1}^{V} (p_j - y_j)\,W_{ij}$$

也就是 $\mathbf{p} - \mathbf{y}$ 与 $W$ 第 $i$ 行的点积。对 $\mathbf{x}$ 的 $d$ 个分量各算一次，就得到损失对 $\mathbf{x}$ 的导数。

Jacobian

上面对 $\mathbf{x}$ 的 $d$ 个分量各求一次和，一共用到 $V \times d$ 个偏导数 $\dfrac{\partial z_j}{\partial x_i}$。把它们排成一个矩阵，第 $j$ 行第 $i$ 列放 $\dfrac{\partial z_j}{\partial x_i}$，即输入的第 $i$ 个分量变化时，输出的第 $j$ 个分量的变化率。这个矩阵称为 $\mathbf{z}$ 对 $\mathbf{x}$ 的 Jacobian，记作 $J$ 或 $\dfrac{\partial \mathbf{z}}{\partial \mathbf{x}}$：

$$J = \begin{bmatrix} \dfrac{\partial z_1}{\partial x_1} & \dfrac{\partial z_1}{\partial x_2} & \cdots & \dfrac{\partial z_1}{\partial x_d} \\[8pt] \dfrac{\partial z_2}{\partial x_1} & \dfrac{\partial z_2}{\partial x_2} & \cdots & \dfrac{\partial z_2}{\partial x_d} \\[4pt] \vdots & \vdots & & \vdots \\[4pt] \dfrac{\partial z_V}{\partial x_1} & \dfrac{\partial z_V}{\partial x_2} & \cdots & \dfrac{\partial z_V}{\partial x_d} \end{bmatrix},\qquad J_{ji} = \frac{\partial z_j}{\partial x_i}$$

一行对应一个输出 $z_j$，它就是 $z_j$ 对 $\mathbf{x}$ 的梯度。一列对应一个输入 $x_i$，给出 $x_i$ 变化时每个输出分量的变化率，也就是求 $\dfrac{\partial \ell}{\partial x_i}$ 时用到的 $V$ 个偏导数。行对应输出，列对应输入，这是引言里说的 numerator layout。一般地，输入有 $n$ 个分量、输出有 $m$ 个分量的函数，Jacobian 是 $m \times n$ 的矩阵，对应形状表里向量对向量一格。

代入上一节的 $\dfrac{\partial z_j}{\partial x_i} = W_{ij}$，得到 $J_{ji} = W_{ij}$，也就是

$$J = W^{T}$$

矩阵乘法的 Jacobian 是权重矩阵的转置。它不依赖 $\mathbf{x}$，因为 $\mathbf{z}$ 是 $\mathbf{x}$ 的线性函数，各处的变化率相同。上一节图中左下的 $\partial \mathbf{z} / \partial x_1$ 和 $\partial \mathbf{z} / \partial x_2$ 两行转置之后，分别是 $J$ 的第 1 列和第 2 列。

把 $\dfrac{\partial \ell}{\partial \mathbf{z}}$ 记作行向量 $\mathbf{g}$，上一节的求和可以用 $J$ 的元素写成

$$\frac{\partial \ell}{\partial x_i} = \sum_{j=1}^{V} g_j\,J_{ji}$$

右边是 $\mathbf{g}$ 与 $J$ 第 $i$ 列的点积。$d$ 个分量合起来，是行向量乘矩阵：

$$\frac{\partial \ell}{\partial \mathbf{x}} = \mathbf{g}\,J = (\mathbf{p} - \mathbf{y})\,W^{T}$$

形状检查：$1 \times V$ 乘 $V \times d$ 得到 $1 \times d$，与 $\mathbf{x}$ 相同。$V$ 条路径的求和对 $d$ 个分量各做一次，合起来是一次行向量乘矩阵。Jacobian 的用处就在这里：它把多条路径的链式法则写成矩阵乘法。

逐元素运算的 Jacobian

LM head 之前各层运算的 Jacobian，也按上一节的方法逐格计算。模型里常见的一类运算是逐元素运算，它们的 Jacobian 有统一的形式。

FFN 的 gate 分支先把输入乘 $W_{gate}$，得到 $\mathbf{a} \in \mathbb{R}^{d_{ff}}$，再对 $\mathbf{a}$ 逐元素作用 Swish，得到 $\mathbf{h} \in \mathbb{R}^{d_{ff}}$，$h_j = \mathrm{Swish}(a_j)$。$h_j$ 只由 $a_j$ 算出，与 $a_i$（$i \neq j$）无关，所以 $\dfrac{\partial h_j}{\partial a_i} = 0$，Jacobian 的非对角元全为零。对角元 $\dfrac{\partial h_j}{\partial a_j}$ 是「标量的导数」一章定义的 $\mathrm{Swish}'(a_j)$。因此

$$\frac{\partial \mathbf{h}}{\partial \mathbf{a}} = \begin{bmatrix} \mathrm{Swish}'(a_1) & 0 & \cdots & 0 \\ 0 & \mathrm{Swish}'(a_2) & \cdots & 0 \\ \vdots & & \ddots & \vdots \\ 0 & 0 & \cdots & \mathrm{Swish}'(a_{d_{ff}}) \end{bmatrix} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)$$

$\mathrm{diag}(\mathbf{v})$ 表示以向量 $\mathbf{v}$ 为对角线的方阵。对每个分量分别作用同一个标量函数的运算称为逐元素运算，sigmoid、指数、平方都属于此类，它们的 Jacobian 都是对角矩阵，对角线上是对应的标量导数。输入有 $n$ 个分量时，这个 Jacobian 有 $n^2$ 个元素，其中只有对角线上的 $n$ 个可能不为零，所以它由对角线上的向量完全确定。vector-Jacobian product 一节利用这一点，把反向计算写成逐元素乘法。

两个向量之间的逐元素运算同理。Swish 的输出 $\mathbf{h}$ 接着与 up 分支的矩阵乘法结果 $\mathbf{b}$ 逐元素相乘：$\mathbf{u} = \mathbf{h} \otimes \mathbf{b}$，$u_j = h_j b_j$。对 $\mathbf{h}$ 求偏导时把 $\mathbf{b}$ 当作常数，$\dfrac{\partial u_j}{\partial h_j} = b_j$，非对角元仍为零；对 $\mathbf{b}$ 求偏导同理：

$$\frac{\partial (\mathbf{h} \otimes \mathbf{b})}{\partial \mathbf{h}} = \mathrm{diag}(\mathbf{b}),\qquad \frac{\partial (\mathbf{h} \otimes \mathbf{b})}{\partial \mathbf{b}} = \mathrm{diag}(\mathbf{h})$$

残差连接把子层的输入与子层的输出相加，结果的第 $j$ 个分量是两个输入的第 $j$ 个分量之和，所以它对两个输入的 Jacobian 都是单位矩阵 $I$。attention 分数除以 $\sqrt{d_h}$ 等于每个分量乘同一个常数，Jacobian 是 $\dfrac{1}{\sqrt{d_h}} I$。

softmax 不属于逐元素运算。LM head 之后的 softmax $p_j = e^{z_j} / \sum_k e^{z_k}$ 的分母含全部 $z_k$，每个 $p_j$ 依赖全部 $V$ 个 logit，所以 Jacobian 不是对角矩阵。「损失对 logits 的梯度」一节把 softmax 和 cross-entropy 合在一起，直接求 $\ell$ 对 $\mathbf{z}$ 的偏导数，没有用到这个 Jacobian。attention 里的 softmax 之后不接 cross-entropy，需要单独计算它的 Jacobian，见后文 softmax 一节。

权重矩阵与整个序列

「LM head 的偏导数」一节对 $W$ 逐个元素求了偏导数，输入也只取了一个位置。模型里有两种矩阵：权重矩阵，例如 LM head 的 $W$；以及 $T$ 个位置的向量按行堆成的矩阵，例如 $T \times d$ 的 $X$。导数的输入或输出是矩阵时，结果位于引言形状表的最后一列或最后一行。其中标量对矩阵一格是训练最终需要的结果，三个灰格（向量对矩阵、矩阵对向量、矩阵对矩阵）是三维或四维数组。下面仍以 LM head 为例，说明这些数组里是什么，以及训练用到其中的哪些部分。

权重矩阵。$\mathbf{z}$ 对 $W$ 的导数属于向量对矩阵：$V$ 个 logit 对 $d \times V$ 个权重，一共 $V \times d \times V$ 个偏导数 $\dfrac{\partial z_j}{\partial W_{im}}$。它们的值在「LM head 的偏导数」一节已经算出：$m = j$ 时是 $x_i$，$m \neq j$ 时是 0。所以这个三维数组里可能不为零的只有 $d \times V$ 个数，取值是 $\mathbf{x}$ 的 $d$ 个分量，每个分量重复 $V$ 次。

训练需要的是损失对每个权重的导数，前面已经逐个算出 $\dfrac{\partial \ell}{\partial W_{ij}} = (p_j - y_j)\,x_i$。每个权重只通过一个 logit 影响损失，所以计算时只用到 $x_i$ 和 $p_j - y_j$，不需要写出这个三维数组。把 $d \times V$ 个结果按 $W$ 的位置排列，第 $i$ 行第 $j$ 列放 $\dfrac{\partial \ell}{\partial W_{ij}}$，得到与 $W$ 同形状的矩阵：

$$\frac{\partial \ell}{\partial W} = \begin{bmatrix} x_1(p_1 - y_1) & \cdots & x_1(p_V - y_V) \\ \vdots & & \vdots \\ x_d(p_1 - y_1) & \cdots & x_d(p_V - y_V) \end{bmatrix} = \mathbf{x}^{T}(\mathbf{p} - \mathbf{y})$$

$\mathbf{x}^T$ 是 $d \times 1$ 的列向量，$\mathbf{p} - \mathbf{y}$ 是 $1 \times V$ 的行向量，两者相乘得到 $d \times V$ 的矩阵，第 $i$ 行第 $j$ 列是 $x_i(p_j - y_j)$。这是形状表里标量对矩阵一格的一个例子。

整个序列。训练时 $T$ 个位置一起计算。$X \in \mathbb{R}^{T \times d}$ 的第 $t$ 行是位置 $t$ 的输入 $\mathbf{x}_t$，$Z = XW \in \mathbb{R}^{T \times V}$ 的第 $t$ 行是 $\mathbf{z}_t = \mathbf{x}_tW$。$Z$ 对 $X$ 的导数属于矩阵对矩阵，一共 $T \times V \times T \times d$ 个偏导数，是一个四维数组。$Z$ 的第 $t$ 行只由 $X$ 的第 $t$ 行算出，所以 $t \neq s$ 时，$\mathbf{z}_t$ 对 $\mathbf{x}_s$ 的偏导数全为零；$t = s$ 时，$\mathbf{z}_t$ 对 $\mathbf{x}_t$ 的 Jacobian 是上面的 $J = W^T$。这个四维数组里可能不为零的只有 $T$ 个 $V \times d$ 的块，每一块都是同一个 $J$。$Z$ 对其中一行 $\mathbf{x}_s$ 的导数属于矩阵对向量，它是这个四维数组的一部分，其中也只有 $J$ 这一块可能不为零。所以反向传播对每个位置分别使用同一个 $J$，与只有一个位置时相同。模型里的大多数运算都像 LM head 一样对每个位置分别计算；attention 让每个位置读取其他位置，是例外，后文 GQA attention 一节单独处理。

上面几个数组的内容都能直接写出来：大部分元素是零，不为零的部分由 $\mathbf{x}$ 或 $J$ 组成。

损失的平均。前面的 $\ell$ 是一个位置的损失。训练用的损失 $L$ 是 $T$ 个位置各自的损失 $\ell_t$ 的平均：$L = \dfrac{1}{T}\sum_{t=1}^{T} \ell_t$，$L$ 对每个 $\ell_t$ 的偏导数都是 $\dfrac{1}{T}$（直接求和、不取平均时是 $1$）。位置 $t$ 的 logits $\mathbf{z}_t$ 只通过 $\ell_t$ 影响 $L$，按单变量链式法则，

$$\frac{\partial L}{\partial \mathbf{z}_t} = \frac{1}{T}\,(\mathbf{p}_t - \mathbf{y}_t)$$

把 $T$ 个位置的这一行堆成 $T \times V$ 的矩阵 $G = \dfrac{1}{T}(P - Y)$，其中 $P$ 和 $Y$ 分别由 $\mathbf{p}_t$ 和 $\mathbf{y}_t$ 按行堆成。损失对 $X$ 的导数逐行计算，第 $t$ 行是 $G$ 的第 $t$ 行乘 $J$，合起来是 $\dfrac{\partial L}{\partial X} = GW^{T}$。权重 $W$ 则被 $T$ 个位置共用，每个 $W_{ij}$ 经过 $T$ 个位置的 logit 影响 $L$。按多条路径的链式法则，$L$ 对它的导数是 $T$ 个位置的贡献之和：

$$\frac{\partial L}{\partial W} = \sum_{t=1}^{T} \mathbf{x}_t^{T}\,\frac{1}{T}(\mathbf{p}_t - \mathbf{y}_t) = X^{T}G$$

$X^T$ 是 $d \times T$，$G$ 是 $T \times V$，矩阵乘法中对 $T$ 的求和就是对 $T$ 个位置的求和。反向传播经过 LM head 时用到的只有 $G$、$W$ 和前向计算时保存的 $X$。

向量链式法则

LM head 是单个运算。FFN 的 gate 分支是两个运算的嵌套：先算 $\mathbf{a} = \mathbf{x}W_{gate}$，再算 $\mathbf{h} = \mathrm{Swish}(\mathbf{a})$，其中 $\mathbf{x} \in \mathbb{R}^{d}$ 是 FFN 在一个位置的输入，$\mathbf{a}, \mathbf{h} \in \mathbb{R}^{d_{ff}}$。两个运算各自的 Jacobian 已经算出：$\dfrac{\partial \mathbf{a}}{\partial \mathbf{x}} = W_{gate}^{T}$，$\dfrac{\partial \mathbf{h}}{\partial \mathbf{a}} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)$。我们要计算整个分支的 Jacobian $\dfrac{\partial \mathbf{h}}{\partial \mathbf{x}}$，即 $d_{ff} \times d$ 个偏导数 $\dfrac{\partial h_j}{\partial x_i}$。

$x_i$ 经由 $a_1, a_2, \ldots, a_{d_{ff}}$ 影响 $h_j$，属于多条路径的情形，每条路径上外层乘内层，再求和：

$$\frac{\partial h_j}{\partial x_i} = \sum_k \frac{\partial h_j}{\partial a_k}\,\frac{\partial a_k}{\partial x_i}$$

右边对 $k$ 求和的形式正是矩阵乘法的定义：第一个矩阵的第 $j$ 行与第二个矩阵的第 $i$ 列的点积。所以整个 Jacobian 是两个 Jacobian 的乘积：

$$\frac{\partial \mathbf{h}}{\partial \mathbf{x}} = \frac{\partial \mathbf{h}}{\partial \mathbf{a}}\,\frac{\partial \mathbf{a}}{\partial \mathbf{x}} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)\; W_{gate}^{T}$$

形状检查：$d_{ff} \times d_{ff}$ 乘 $d_{ff} \times d$ 得到 $d_{ff} \times d$，对应 $d_{ff}$ 个输出和 $d$ 个输入。

这是向量链式法则：外层的 Jacobian 乘内层的 Jacobian，相乘顺序与单变量版本相同。嵌套更多层时，把各层的 Jacobian 按从外到内的顺序相乘。

vector-Jacobian product

反向传播需要的是标量损失对各个量的导数。Jacobian 一节对 LM head 算出了 $\dfrac{\partial \ell}{\partial \mathbf{x}} = \mathbf{g}J$：损失对输出的导数 $\mathbf{g}$ 是一个行向量，乘输出对输入的 Jacobian，得到损失对输入的导数。其他运算也是这样。设一个运算的输入是 $\mathbf{a}$，输出是 $\mathbf{h}$，Jacobian 是 $J = \dfrac{\partial \mathbf{h}}{\partial \mathbf{a}}$，已知 $\mathbf{g} = \dfrac{\partial L}{\partial \mathbf{h}}$。$a_k$ 经由 $h_1, h_2, \ldots$ 影响 $L$，按多条路径求和，推导与 LM head 相同：

$$\frac{\partial L}{\partial \mathbf{a}} = \mathbf{g}\,J$$

结果仍是行向量，与 $\mathbf{a}$ 同形状。这个运算称为 vector-Jacobian product。反向传播每经过一个运算做的就是它：取损失对该运算输出的导数 $\mathbf{g}$，算出损失对输入的导数 $\mathbf{g}J$，向前一层传递。

连续经过多个运算时，也可以先按向量链式法则把各个 Jacobian 乘起来。以 FFN 的 gate 分支为例，设 $\mathbf{g} = \dfrac{\partial L}{\partial \mathbf{h}}$：

$$\frac{\partial L}{\partial \mathbf{x}} = \mathbf{g}\,\Big(\mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)\,W_{gate}^{T}\Big) = \Big(\mathbf{g}\,\mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)\Big)\,W_{gate}^{T}$$

矩阵乘法满足结合律，两种顺序结果相同。右边的顺序从 $\mathbf{g}$ 开始，每一步都是行向量乘一个 Jacobian，结果仍是行向量，不需要算出两个 Jacobian 的乘积。对一般的 Jacobian，矩阵乘矩阵的计算量远大于行向量乘矩阵。反向传播采用右边的顺序：从损失开始，逐个运算向前做 vector-Jacobian product。

计算 $\mathbf{g}J$ 也不需要构造 $J$，下面是最常见的两种 Jacobian：

对角 Jacobian。$J = \mathrm{diag}(\mathbf{v})$ 时，$\mathbf{g}J$ 的第 $k$ 个分量是 $g_k v_k$，也就是逐元素相乘：

$$\mathbf{g}\,\mathrm{diag}(\mathbf{v}) = \mathbf{g} \otimes \mathbf{v}$$

Swish 的反向是 $\mathbf{g} \otimes \mathrm{Swish}'(\mathbf{a})$，一次 $d_{ff}$ 个元素的逐元素乘，而不是一次 $d_{ff} \times d_{ff}$ 的矩阵乘。

矩阵乘法的 Jacobian。$\mathbf{a} = \mathbf{x}W$ 时 $J = W^T$，$\dfrac{\partial L}{\partial \mathbf{x}} = \mathbf{g}\,W^{T}$，与 LM head 的 $(\mathbf{p} - \mathbf{y})\,W^{T}$ 形式相同，是一次普通的矩阵乘法。

损失对权重的导数最能说明不构造 Jacobian 的好处。按向量链式法则，损失对 $W_{gate}$ 的导数要经过 $\dfrac{\partial \mathbf{a}}{\partial W_{gate}}$，这是形状表中向量对矩阵的三维数组，共 $d_{ff} \times d \times d_{ff}$ 个数。取 Llama 2 7B 的 $d_{ff} = 11008$、$d = 4096$，这个数组约有 $5 \times 10^{11}$ 个元素，约为该模型全部参数量的七十倍，放不进显存。「权重矩阵与整个序列」一节对 LM head 算出的 $\dfrac{\partial \ell}{\partial W} = \mathbf{x}^{T}(\mathbf{p} - \mathbf{y})$ 中，$\mathbf{p} - \mathbf{y}$ 就是损失对输出的导数 $\mathbf{g}$。那里的推导只用到每个权重只出现在一个输出里，所以对任何矩阵乘法 $\mathbf{a} = \mathbf{x}W$ 都成立：

$$\frac{\partial L}{\partial W} = \mathbf{x}^{T}\mathbf{g}$$

$\mathbf{x}^T$ 是 $d \times 1$，$\mathbf{g}$ 是 $1 \times d_{ff}$，乘出来 $d \times d_{ff}$，和 $W$ 同形状。序列有 $T$ 个位置时，与 LM head 的情形相同，$\dfrac{\partial L}{\partial W} = X^T G$。

自动微分系统为每个算子登记的反向函数，输入是 $\mathbf{g}$，输出是 $\mathbf{g}J$，计算时不单独构造 $J$。因此反向传播只做几次与前向同规模的矩阵乘法和逐元素乘，开销不超过前向计算的几倍，与引言中 cheap gradient principle 的结论一致。

每个算子一条反向规则

每个运算的反向规则都可以写成同一个格式。对图里的每个方框：前向算出 输出 $= f(\text{输入})$；反向的输入是 $G = \dfrac{\partial L}{\partial\,\text{输出}}$，它和输出同形状；返回 $\dfrac{\partial L}{\partial\,\text{输入}}$，和输入同形状；方框里有权重的，再返回 $\dfrac{\partial L}{\partial W}$，和 $W$ 同形状。自动微分系统按这个格式为每种运算登记一条反向规则，backward() 按前向的相反顺序逐条调用。

记号：大写 $X$、$G$ 是 $T$ 个位置堆成的矩阵，$X$ 是 $T \times d$；小写 $\mathbf{x}$ 是其中一行。

矩阵乘法

前向：$Z = XW$，$X$ 是 $T \times d$，$W$ 是 $d \times m$，$Z$ 是 $T \times m$。反向的输入是 $G$（$T \times m$）：

$$\frac{\partial L}{\partial X} = G\,W^{T},\qquad \frac{\partial L}{\partial W} = X^{T}G$$

形状检查$G W^T$：$T \times m$ 乘 $m \times d$ 得 $T \times d$，和 $X$ 相同。$X^T G$：$d \times T$ 乘 $T \times m$ 得 $d \times m$，和 $W$ 相同。

上一章已经对一行推过，$T$ 行堆在一起时，$X^T G$ 把 $T$ 个位置对 $W$ 的贡献加在了一起。这一条覆盖图里所有带权重的方框：$W_Q$、$W_K$、$W_V$、$W_O$、$W_{gate}$、$W_{up}$、$W_{down}$、$W_{out}$。attention 里的 $QK^T$ 和 $PV$ 也是矩阵乘法，只是两边都是 activation，没有权重：对 $S = QK^T$，把 $K^T$ 放在 $W$ 的位置，得到 $\dfrac{\partial L}{\partial Q} = G K$，$\dfrac{\partial L}{\partial K} = G^T Q$。

Embedding

前向：第 $t$ 个位置取出 $E$ 的第 $\text{tok}_t$ 行，$X_0[t] = E[\text{tok}_t]$。这等价于一个 one-hot 矩阵（$T \times V$，每行只有一个 1）乘 $E$，所以它是矩阵乘法的特例。

反向的输入是 $G$（$T \times d$）：$\dfrac{\partial L}{\partial E}$ 从全零的 $V \times d$ 矩阵开始，把 $G$ 的第 $t$ 行加到第 $\text{tok}_t$ 行上。同一个 token 在序列里出现几次，对应行就累加几次。token_ids 是整数，不对它求导，反向传播在这里结束。

逐元素运算与残差

以下几条的 Jacobian 都是对角矩阵，反向全部是逐元素乘，不含矩阵乘法。

逐元素函数 $H = \mathrm{Swish}(A)$：$\dfrac{\partial L}{\partial A} = G \otimes \mathrm{Swish}'(A)$。sigmoid、指数和其他逐元素函数同理，换成对应的标量导数。

逐元素乘 $H = A \otimes B$：$\dfrac{\partial L}{\partial A} = G \otimes B$，$\dfrac{\partial L}{\partial B} = G \otimes A$。

残差相加 $Y = X + H$：$\dfrac{\partial L}{\partial H} = G$，$\dfrac{\partial L}{\partial X}$ 中来自这条路径的部分同样等于 $G$。$X$ 还通过子层影响 $Y$，该路径传回的导数与这份 $G$ 相加，最终 $\dfrac{\partial L}{\partial X} = G + (\text{子层传回的})$。实现上先把 $G$ 交给子层算完，再做这次加法。

常数缩放 $S = QK^{T} / \sqrt{d_h}$：$\dfrac{\partial L}{\partial (QK^{T})} = G / \sqrt{d_h}$。causal mask 是把常数 $-\infty$ 加到被遮住的位置，它没有参数，被遮住的位置 softmax 输出为零，导数也为零，反向不需要处理。

softmax

对一行 $\mathbf{s} \in \mathbb{R}^{n}$：$p_j = \dfrac{e^{s_j}}{\sum_k e^{s_k}}$。每个 $p_j$ 依赖全部 $s_i$，Jacobian 不是对角的。用商法则算 $\dfrac{\partial p_j}{\partial s_i}$，分子 $e^{s_j}$ 只在 $i = j$ 时依赖 $s_i$，分母对每个 $s_i$ 的导数是 $e^{s_i}$：

$$\frac{\partial p_j}{\partial s_i} = \frac{[i=j]\,e^{s_j}\sum_k e^{s_k} - e^{s_j}e^{s_i}}{\big(\sum_k e^{s_k}\big)^2} = [i=j]\,p_j - p_j p_i$$

$[i = j]$ 在 $i = j$ 时为 1，否则为 0。整个 Jacobian 是 $\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$，即一个对角矩阵减去一个秩为 1 的矩阵。反向按 $\mathbf{g}J$ 计算：

$$\frac{\partial L}{\partial \mathbf{s}} = \mathbf{g}\,\big(\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T\big) = \mathbf{g} \otimes \mathbf{p} - (\mathbf{g}\cdot\mathbf{p})\,\mathbf{p} = \mathbf{p} \otimes \big(\mathbf{g} - (\mathbf{g}\cdot\mathbf{p})\big)$$

最后一个式子里 $\mathbf{g}\cdot\mathbf{p}$ 是标量，从 $\mathbf{g}$ 的每个分量中减去它。这个 Jacobian 不是对角矩阵，反向仍是一次点积、一次减法、一次逐元素乘，计算量与 $n$ 成正比。attention 对 $T \times T$ 的分数矩阵逐行执行这一步，LM head 之后对 $T \times V$ 的 logits 逐行执行。

cross-entropy

前向：第 $t$ 个位置的损失 $\ell_t = -\ln p_{t,\,y_t}$，$y_t$ 是目标 token；$L = \dfrac{1}{T}\sum_t \ell_t$。

反向：$L$ 对 $p_{t,j}$ 的导数，只有 $j = y_t$ 那一项不为零，用对数规则和 $1/T$：

$$\frac{\partial L}{\partial p_{t,j}} = \begin{cases} -\dfrac{1}{T\,p_{t,y_t}} & j = y_t \\[6pt] 0 & j \neq y_t \end{cases}$$

把它作为 $\mathbf{g}$ 代入 softmax 的反向规则。$\mathbf{g}$ 只有一个非零分量，所以 $\mathbf{g}\cdot\mathbf{p} = -\dfrac{1}{T}$，于是 $\mathbf{p} \otimes (\mathbf{g} - (\mathbf{g}\cdot\mathbf{p}))$ 的第 $j$ 个分量是 $p_{t,j}\big(g_j + \frac{1}{T}\big)$。$j = y_t$ 时是 $\frac{1}{T}(p_{t,y_t} - 1)$，其余是 $\frac{1}{T}p_{t,j}$。合起来：

$$\frac{\partial L}{\partial \mathbf{s}_t} = \frac{1}{T}\big(\mathbf{p}_t - \mathbf{y}_t\big),\qquad \frac{\partial L}{\partial S} = \frac{1}{T}\,(P - Y)$$

$\mathbf{y}_t$ 是目标 token 的 one-hot 向量，$Y$ 是它们堆成的 $T \times V$ 矩阵。损失对 logits 的导数等于预测分布减去目标分布。实现中 softmax 和 cross-entropy 通常合成一个算子（PyTorch 的 F.cross_entropy），原因有两个：合并后的反向规则只需一次减法，不必先算出 $-1/p$ 再代回 softmax 的反向；前向按 $\ln p_j = s_j - \ln\sum_k e^{s_k}$ 计算，配合减去每行最大值，避免 $e^{s_j}$ 溢出和 $p_j$ 下溢后取对数。

GQA attention

attention 是上面几条规则的组合，没有新规则。对一个 query head $i$，设它所在的组是 $j$，前向依次是：

  1. 三次矩阵乘法：$Q_i = XW_Q^{(i)}$，$K_j = XW_K^{(j)}$，$V_j = XW_V^{(j)}$。
  2. 矩阵乘法加常数缩放加 mask：$S_i = Q_iK_j^T/\sqrt{d_h} + M$。
  3. 逐行 softmax：$P_i = \mathrm{softmax}(S_i)$。
  4. 矩阵乘法：$A_i = P_iV_j$。
  5. 拼接所有 head，矩阵乘法：$A = [A_1 \cdots A_{n_h}]\,W_O$。

反向按相反顺序：$W_O$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial W_O}$，并把 $G$ 拆回每个 head 的 $\dfrac{\partial L}{\partial A_i}$；$A_i = P_iV_j$ 给出 $\dfrac{\partial L}{\partial P_i}$ 和 $V_j$ 的一份梯度；softmax 的反向给出 $\dfrac{\partial L}{\partial S_i}$；除以 $\sqrt{d_h}$；$S_i$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial Q_i}$ 和 $K_j$ 的一份梯度。

需要相加的地方有两处。第一，$K_j$ 和 $V_j$ 被同一组的 $n_h / n_{kv}$ 个 head 共用，每个 head 各传回一份梯度，$\dfrac{\partial L}{\partial K_j}$ 是这些梯度之和，之后才用矩阵乘法规则得到 $\dfrac{\partial L}{\partial W_K^{(j)}} = X^T\dfrac{\partial L}{\partial K_j}$。第二，$X$ 同时进入了 $Q$、$K$、$V$ 三次矩阵乘法，$\dfrac{\partial L}{\partial X}$ 是这三条路径的梯度之和，再加上残差传回的一份。

FP32 到 BF16 的转换

前向：$W_{\text{bf16}} = \mathrm{round}(W_{\text{fp32}})$，把每个数舍入到 BF16 能表示的最近的值。这一步在图里的每个带权重的方框内部，矩阵乘法之前。

这个函数是阶梯函数：在几乎所有点导数为零，在跳变点不可导。按定义求导会使梯度在这里变为零，权重无法更新。所以框架不按定义求导，而是登记一条约定：

$$\frac{\partial L}{\partial W_{\text{fp32}}} := \frac{\partial L}{\partial W_{\text{bf16}}}\ \text{转回 FP32}$$

也就是把舍入当作恒等运算，导数原样通过。前向用不可导的舍入，反向用恒等函数替代它的导数，这种做法称为 straight-through estimator，Bengio 等人在 2013 年的论文中对它做了系统的讨论[4]。这样得到的梯度是在舍入后的 BF16 权重处算出的，却被当作 FP32 权重处的梯度使用，两者的差别与舍入误差同量级，训练中不对这部分误差做修正。

算出梯度之后，更新也不能直接加在 BF16 权重上。单步更新 $\eta\,\partial L/\partial w$ 相对权重自身的幅度，往往小于 BF16 相邻可表示数的相对间隔（BF16 存储 7 位尾数，相对间隔约 $2^{-7}$），加上去之后会被舍入丢掉。这个问题来自 BF16 的精度，与 straight-through estimator 无关。Micikevicius 等人在 2018 年的混合精度训练论文里针对 FP16 说明了这个问题[3]，解决办法是保留一份 FP32 主权重：更新累加在 FP32 上，每一步前向再舍入成 BF16。

权重导数本身也由 BF16 的矩阵乘法算出：前向保存的 $X$ 和反向传回的 $G$ 都是 BF16。$X^T G$ 的每个元素是对序列长度 $T$ 求和的内积。同一篇论文指出，这类内积要把逐项乘积累加到 FP32，写回内存时再转换成低精度；不这样做，一些模型达不到 FP32 训练的精度[3]。写回的 $\dfrac{\partial L}{\partial W_{\text{bf16}}}$ 再按上面的约定转回 FP32，用于更新主权重。
