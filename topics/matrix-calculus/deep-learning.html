引言

训练一个模型，做的事情只有一件：调整参数，让损失变小。模型里有几十亿个参数，每调整一次，都要对每个参数回答同一个问题：这个参数往哪个方向动、动多少，损失才会下降？

回答这个问题的工具是导数。单变量微积分里，导数回答的是「输入变化一点，输出变化多少」。训练模型时问题没有变，只是输入和输出都不再是单个数：损失是一个数，参数是一个矩阵，中间每一层的输出是一个向量或者一个矩阵。把导数从「数对数」扩展到「向量对向量」「数对矩阵」，就是矩阵微积分。

PyTorch 这样的框架里，loss.backward() 一行就把所有参数的导数算完了。你不必亲手推导也能训练模型。但是读论文、查训练不收敛的原因、写一个框架没有提供的算子时，你需要知道 backward 到底算了什么。本文的目标就是把这件事讲清楚，讲到你能自己推出一个 Transformer 的完整梯度。

我们要处理的模型

先看这个模型的全貌。下图是一个 decoder-only Transformer 做语言模型训练时，从输入 token 到损失的完整计算过程。每个方框是一次计算，每个圆角框是一份数据，框里标着它的形状。$T$ 是序列长度，$d$ 是模型宽度，$V$ 是词表大小。为了看清形状，图中省略了 batch 维度。

后面的每一章都从这张图里取一块来讲。现在不需要理解每个方框内部发生了什么，只需要记住三件事：

  1. 最上面进来的是整数，最下面出去的是一个 scalar，中间全是矩阵。
  2. 我们要求的，是最下面这个 scalar 对图中每一个权重矩阵的导数。
  3. 求导要沿着箭头的反方向，一层一层往回传。每经过一个方框，就要用到那个方框对应的一条求导规则。

图里有两个方框内部的结构本文后面会反复用到。如果你已经熟悉它们，可以跳过下面两个折叠块。

什么是 SwiGLU FFN

FFN 对序列里的每个位置独立计算，所以只看一个位置的向量 $\mathbf{x}$（长度 $d$）就够了：

$$\mathbf{h} = \big(\mathrm{Swish}(\mathbf{x}W_{gate}) \otimes \mathbf{x}W_{up}\big)\,W_{down}$$

三个权重矩阵：$W_{gate}$ 和 $W_{up}$ 都是 $d \times d_{ff}$，$W_{down}$ 是 $d_{ff} \times d$。$\otimes$ 表示逐元素相乘。Swish 逐元素作用在向量上，对每个数做的是 $\mathrm{Swish}(z) = z\,\sigma(z)$，其中 $\sigma(z) = \dfrac{1}{1+e^{-z}}$ 是 sigmoid 函数。

计算顺序：$\mathbf{x}$ 分别乘两个矩阵，得到两个长度为 $d_{ff}$ 的向量；一个经过 Swish，然后和另一个逐元素相乘；结果乘 $W_{down}$，回到长度 $d$。Llama、Qwen、Mistral 这些模型的 FFN 都是这个结构。

本文选它做主线例子，因为这一个式子里有矩阵乘法、逐元素运算、标量函数作用到向量上、三层嵌套。矩阵微积分要讲的规则，它全部用到。

什么是 GQA Attention

Attention 让每个位置的向量能读取它前面所有位置的信息。输入 $X$ 是 $T \times d$ 的矩阵，每一行是一个位置。

每个 query head $i$（一共 $n_h$ 个）有自己的 $W_Q^{(i)}$，形状 $d \times d_h$。key 和 value 只有 $n_{kv}$ 组，每组 $W_K^{(j)}$ 和 $W_V^{(j)}$（都是 $d \times d_h$）被 $n_h / n_{kv}$ 个 query head 共用。这是 Grouped-Query Attention 和普通 multi-head attention 的唯一区别。

对一个 query head $i$，设它所属的组是 $j$：

$$Q_i = XW_Q^{(i)},\qquad K_j = XW_K^{(j)},\qquad V_j = XW_V^{(j)}$$ $$A_i = \mathrm{softmax}\!\left(\frac{Q_iK_j^{T}}{\sqrt{d_h}} + M\right) V_j$$

$M$ 是 causal mask，把每个位置后面的位置置为 $-\infty$，让它只能看到自己和前面的位置。softmax 对矩阵的每一行独立作用。所有 head 的 $A_i$ 按列拼接成 $T \times n_h d_h$，再乘 $W_O$（$n_h d_h \times d$）。

本文选它有两个原因。第一，softmax 的导数是全文唯一一个既不是对角矩阵、也不是权重矩阵的 Jacobian。第二，一组 K/V 权重被多个 head 共用，求它的导数时要把每个 head 传回来的梯度加起来。这是「一个变量影响多条路径」在真实模型里的样子。

什么是导数

从最简单的情况开始：一个输入 $x$，一个输出 $y = f(x)$，两个都是单个数。

导数要回答的问题是：$x$ 变化一点，$y$ 跟着变化多少。把它写成比值：

$$\frac{\Delta y}{\Delta x} = \frac{f(x+\Delta x) - f(x)}{\Delta x}$$

这个比值有一个几何含义。在 $f$ 的图像上取 $x$ 和 $x+\Delta x$ 两个点，过它们画一条直线，比值就是这条直线的斜率。

问题在于，比值取决于 $\Delta x$ 有多大。取 $f(x) = x^3$，在 $x = 1$ 处：$\Delta x = 1$ 时比值是 $7$，$\Delta x = 0.1$ 时是 $3.31$，$\Delta x = 0.01$ 时是 $3.0301$。$\Delta x$ 越小，比值越接近 $3$，而且不会越过 $3$。下面的图里可以亲手做这件事：拖动黑点选一个位置，先把 $\Delta x$ 拉大，再把它缩回去，看过两点的直线转向哪里。

$\Delta x$ 缩到足够小时，过两点的直线停在一个确定的位置上，不再转动。这条线叫切线，导数 $f'(x)$ 就是切线的斜率。它是一个确定的数，不再依赖 $\Delta x$。习惯上把「$\Delta x$ 已经缩到极小之后的比值」写成 $\dfrac{dy}{dx}$，字母 $d$ 表示这是一个极小的变化量。于是导数的含义可以写成一句话：

$$dy = f'(x)\,dx$$

输入变化 $dx$，输出就变化 $f'(x)$ 倍的 $dx$。后面讲向量和矩阵的时候，这句话会原样保留，只是 $f'(x)$ 从一个数变成一个向量、再变成一个矩阵。

图里还能看到另一件事：$x_0$ 每换一个位置，切线就换一条，斜率也换一个值。所以 $f'$ 本身也是一个关于 $x$ 的函数，图的下半部分画的就是它。对 $x^3$ 来说 $f'(x) = 3x^2$，对 $\sin x$ 来说 $f'(x) = \cos x$。求导，就是从 $f$ 得到 $f'$ 的过程。

这和训练模型的关系是：损失 $L$ 是所有参数的函数。对其中一个参数 $w$，导数 $\dfrac{\partial L}{\partial w}$ 告诉我们 $w$ 增加一点时 $L$ 是增加还是减少、变化多快。梯度下降就是让每个参数往使 $L$ 减小的方向走一小步：$w \leftarrow w - \eta\,\dfrac{\partial L}{\partial w}$。这里用 $\partial$ 而不是 $d$，是因为 $L$ 还依赖别的参数，下一章会解释这个符号。全部的难点不在这一步，而在于怎么把几十亿个 $\dfrac{\partial L}{\partial w}$ 算出来。

深度学习里的导数长什么样

把 $dy = f'(x)\,dx$ 放回模型里看。模型里的输入和输出有三种形状：一个数（标量），一列数（向量），一张表（矩阵）。输入三种、输出三种，组合起来一共九种「输出对输入求导」。它们的结果各是什么形状？

先说结论：结果里要放下「每一个输出分量对每一个输入分量」的导数。输出有 $m$ 个数，输入有 $n$ 个数，结果就有 $m \times n$ 个数。下表列出了全部九种情况。现在不需要看懂每个格子里的记号，先看形状，看每一格在模型里对应什么：

标量 $y$ scalar$$\frac{dy}{dx}$$例：$\mathrm{Swish}(z)$ 对 $z$。 向量，$n$ 个数。叫做梯度$$\frac{\partial y}{\partial \mathbf{x}} = \Big[\frac{\partial y}{\partial x_1}\ \ \frac{\partial y}{\partial x_2}\ \ \cdots\ \ \frac{\partial y}{\partial x_n}\Big]$$例：损失 $L$ 对某一个位置的 logits 向量。 矩阵，$p \times q$，和 $W$ 同形状$$\Big(\frac{\partial y}{\partial W}\Big)_{ij} = \frac{\partial y}{\partial W_{ij}}$$例：损失 $L$ 对 $W_{down}$。训练要的就是这一格。

看这张表，有两件事现在就可以记住。

第一，训练最终要的东西全在第一行。损失是一个数，所以「损失对任何东西的导数」永远和那个东西同一个形状：对标量是标量，对向量是向量，对矩阵是矩阵。PyTorch 里 w.grad 和 w 形状相同，就是这个原因。

第二，第二行和第三行的大对象不是最终结果，它们出现在中间。损失对 $W_{down}$ 的导数，要经过「损失对 $\mathbf{h}$」和「$\mathbf{h}$ 对 $W_{down}$」两步，第二步就是右下角那种三维数组。但是反向传播从来不把它真的算出来，它有办法直接得到两步合起来的结果。这是链式法则那一章的核心，也是反向传播能在几十亿个参数上跑起来的原因。

最后是一个约定。本文写向量对向量的导数时，行对应输出，列对应输入，上表 Jacobian 那一格就是这样排的。这种排法叫 numerator layout。有的书和论文把它转置过来写，叫 denominator layout。看到别处的公式和本文形状对不上时，先检查这一点。

复习：标量求导规则

后面所有对向量、矩阵的求导，最后一步都会落到对单个数求导。所以先把标量的规则列全。这些规则你在微积分课上都见过，这里的重点不是重新学，而是知道每一条在我们的模型里出现在哪。点击表里的一行，会显示这条规则在模型里被用到的位置。

表里有两点值得说明。

第一，函数只有一个参数时，很多资料把 $\dfrac{d}{dx}f(x)$ 简写成 $f'(x)$。本文在讲标量时也这样写，但是一旦出现多个变量就改用完整写法，因为 $f'$ 没有说明是对哪个变量求导。

第二，可以把 $\dfrac{d}{dx}$ 看作一个运算符：它接收一个函数，返回另一个函数。这个运算符对加法可以拆开，常数可以提到它前面。这样一来，对复杂表达式求导就变成先拆分、再分别求导、最后组合：

$$\frac{d}{dx}\,9(x + x^2) = 9\,\frac{d}{dx}(x + x^2) = 9\Big(\frac{d}{dx}x + \frac{d}{dx}x^2\Big) = 9(1 + 2x) = 9 + 18x$$

后面对向量和矩阵求导，用的是同一个办法：把大表达式拆成已知规则能处理的小块，分别求导，再按正确的形状组合起来。

练习：对 Swish 求导

Swish 是表里唯一一条需要两步才能得到的规则，把它推一遍，正好把乘积法则和链式法则各用一次。

把 Swish 写成两个函数的乘积：$\mathrm{Swish}(x) = x \cdot \sigma(x)$。乘积法则给出：

$$\mathrm{Swish}'(x) = 1 \cdot \sigma(x) + x \cdot \sigma'(x)$$

$\sigma'(x) = \sigma(x)\,(1-\sigma(x))$，这是表里 sigmoid 那一行，它由幂函数规则和链式法则得到。代入：

$$\mathrm{Swish}'(x) = \sigma(x) + x\,\sigma(x)\,(1-\sigma(x)) = \sigma(x)\,\big(1 + x\,(1-\sigma(x))\big)$$

回到上一节的图里选 $\mathrm{Swish}(x)$，拖动黑点，检查切线斜率和这个式子算出来的值是否一致。$x = 0$ 处应当是 $0.5$。

向量微积分与偏导数入门

上一章的函数只有一个输入。模型里没有任何一步是这样的：损失依赖全部几十亿个参数，一层的输出依赖整个输入矩阵。所以第一个要回答的问题是：输入有很多个数的时候，「输入变化一点，输出变化多少」这句话怎么说？

偏导数：一次只动一个输入

从两个输入开始。取 $f(x, y) = 3x^2 y$，两个输入，一个输出。「输入变化一点」现在有两种做法：动 $x$，或者动 $y$。

先只动 $x$，把 $y$ 固定住。这时 $f$ 只剩一个会变的输入，它是一个单变量函数，上一章的方法可以直接用：画出它的图像，在 $x$ 处取切线，斜率就是「$x$ 动一点，$f$ 动多少」。这个斜率叫 $f$ 对 $x$ 的偏导数，写作 $\dfrac{\partial f}{\partial x}$。

计算它没有任何新东西。$y$ 被固定，所以对 $\dfrac{\partial}{\partial x}$ 来说 $y$ 是常数，按复习表里「常数倍」那一行处理：

$$\frac{\partial}{\partial x}\,3x^2y = 3y \cdot \frac{d}{dx}x^2 = 3y \cdot 2x = 6xy$$

同样，固定 $x$ 只动 $y$，得到对 $y$ 的偏导数：

$$\frac{\partial}{\partial y}\,3x^2y = 3x^2 \cdot \frac{d}{dy}y = 3x^2$$

符号 $\partial$ 读作「偏」。它和 $d$ 的区别只有一点：$\partial$ 提醒你这个函数还有别的输入，此刻它们被固定了。对只有一个输入的函数，$\dfrac{\partial f}{\partial x}$ 和 $\dfrac{df}{dx}$ 是同一个东西。

下面的图把这件事画出来。左边是 $f(x, y)$ 在每个位置的值，红色是正，蓝色是负。拖动黑点选一个位置 $(x_0, y_0)$。右边两张小图分别是「固定 $y = y_0$，只动 $x$」和「固定 $x = x_0$，只动 $y$」得到的两条单变量曲线，也就是左图上沿绿色虚线和粉色虚线切出来的两个剖面，各带一条切线，两个斜率就是两个偏导数。

梯度：所有输入一起动

只动一个输入是为了把问题拆开。真正训练的时候，几十亿个参数是一起动的。所以要回答：$x$ 动 $dx$，$y$ 同时动 $dy$，$f$ 动多少？

答案是两部分相加：

$$df = \frac{\partial f}{\partial x}\,dx + \frac{\partial f}{\partial y}\,dy$$

为什么可以相加：变化量足够小的时候，「先动 $x$ 再动 $y$」和「一起动」结果相同。第一步 $f$ 变化 $\dfrac{\partial f}{\partial x}\,dx$，第二步再变化 $\dfrac{\partial f}{\partial y}\,dy$。上面的图里可以验证：把 $\Delta x$ 和 $\Delta y$ 调到很小，真实的 $\Delta f$ 和用这个式子算出来的值就对上了。调大，两者会分开，因为这个式子只在「一点点」的范围内成立，和切线只在切点附近贴着曲线是同一件事。

把这个式子写成向量的形式。输入的变化是一个向量 $d\mathbf{x} = [\,dx\ \ dy\,]$，两个偏导数排成另一个向量：

$$\nabla f = \Big[\,\frac{\partial f}{\partial x}\ \ \frac{\partial f}{\partial y}\,\Big] = [\,6xy\ \ 3x^2\,]$$

这个向量叫 $f$ 的梯度，$\nabla$ 读作 nabla。于是：

$$df = \nabla f \cdot d\mathbf{x}$$

和上一章的 $dy = f'(x)\,dx$ 对照：句子没有变，还是「输入变化一点，输出变化它的多少倍」，只是「倍数」从一个数变成了一个向量，「乘」变成了点积。输入有 $n$ 个数时，梯度就是 $n$ 个偏导数排成一行，式子完全一样。这就是第一章形状表里「标量对向量」那一格。

梯度告诉我们什么

点积 $\nabla f \cdot d\mathbf{x}$ 有一个几何性质：步长固定时，$d\mathbf{x}$ 和 $\nabla f$ 方向相同，点积最大；方向相反，点积最小，也就是最负。所以梯度指向 $f$ 增加最快的方向，$-\nabla f$ 指向 $f$ 减少最快的方向。图里的紫色箭头就是 $\nabla f$，把 $(\Delta x, \Delta y)$ 调到和它相反的方向，$\Delta f$ 会是同样步长下所有方向里最负的。

这就是梯度下降。损失 $L$ 是全部参数的函数，算出 $\nabla L$，让每个参数沿 $-\nabla L$ 走一小步，$L$ 就以最快的速度下降：

$$w \leftarrow w - \eta\,\frac{\partial L}{\partial w}\qquad\text{对每一个参数 } w$$

每个参数只看自己那一个偏导数：它说明这个参数动一点，损失动多少。PyTorch 里 w.grad 存的就是 $\dfrac{\partial L}{\partial w}$，形状和 $w$ 相同，因为 $w$ 里的每一个数都有自己的偏导数。

放回模型里

用图里最简单的一步试一下。LM head 对一个位置做的是 $\mathbf{z} = \mathbf{x} W_{out}$，$\mathbf{x}$ 长度 $d$，$\mathbf{z}$ 长度 $V$。展开第 $j$ 个 logit：

$$z_j = \sum_{k=1}^{d} x_k\,W_{kj}$$

它是 $d$ 个输入 $x_k$ 和 $d$ 个权重 $W_{kj}$ 的函数。对其中一个求偏导，其余全部当常数，和式里只剩一项：

$$\frac{\partial z_j}{\partial x_k} = W_{kj},\qquad \frac{\partial z_j}{\partial W_{kj}} = x_k$$

这两个结果后面会反复出现：一个 logit 对某个输入的敏感程度，是连接它们的那个权重；对某个权重的敏感程度，是那个权重乘的那个输入。

到这里输出还是一个数。$\mathbf{z}$ 有 $V$ 个分量，每个 $z_j$ 都是 $\mathbf{x}$ 的函数，各有自己的梯度。把 $V$ 个梯度逐行排起来，就是形状表里「向量对向量」那一格的矩阵。这是下一章的内容。

矩阵微积分

上一章的输出始终是一个数。模型里的每一步，输出都是向量或矩阵：LM head 一次算出 $V$ 个 logit，Swish 一次作用在 $d_{ff}$ 个数上。这一章把「输入变化一点，输出变化多少」推广到输出也是向量的情形，然后看几种常见运算的答案各是什么样子。

Jacobian：向量对向量的导数

还是 LM head 的那一步，$\mathbf{z} = \mathbf{x} W$，输入 $\mathbf{x}$ 有 $d$ 个数，输出 $\mathbf{z}$ 有 $V$ 个数。「$\mathbf{x}$ 动一点」有 $d$ 个方向可以动，「$\mathbf{z}$ 跟着动」有 $V$ 个分量在动。要把关系说完整，需要回答 $V \times d$ 个问题：

每一个问题第 $i$ 个输入 $x_i$ 动一点，第 $j$ 个输出 $z_j$ 跟着动多少？答案是偏导数 $\dfrac{\partial z_j}{\partial x_i}$。

把这些答案排成一个矩阵，第 $j$ 行第 $i$ 列放 $\dfrac{\partial z_j}{\partial x_i}$。这个矩阵叫 Jacobian，记作 $J$：

$$J = \begin{bmatrix} \dfrac{\partial z_1}{\partial x_1} & \dfrac{\partial z_1}{\partial x_2} & \cdots & \dfrac{\partial z_1}{\partial x_d} \\[8pt] \dfrac{\partial z_2}{\partial x_1} & \dfrac{\partial z_2}{\partial x_2} & \cdots & \dfrac{\partial z_2}{\partial x_d} \\[4pt] \vdots & \vdots & & \vdots \\[4pt] \dfrac{\partial z_V}{\partial x_1} & \dfrac{\partial z_V}{\partial x_2} & \cdots & \dfrac{\partial z_V}{\partial x_d} \end{bmatrix},\qquad J_{ji} = \frac{\partial z_j}{\partial x_i}$$

它有两种读法。一行对应一个输出 $z_j$，这一行就是 $z_j$ 的梯度，记录了 $z_j$ 对每个输入的敏感程度。一列对应一个输入 $x_i$，这一列记录了 $x_i$ 牵动每个输出的程度。第一章里说过的约定就是这个：行对应输出，列对应输入。

对 $\mathbf{z} = \mathbf{x}W$ 来说，上一章已经算过每个格子：$\dfrac{\partial z_j}{\partial x_i} = W_{ij}$。所以 $J_{ji} = W_{ij}$，也就是

$$J = W^{T}$$

这个结果值得停一下：矩阵乘法的 Jacobian 就是权重矩阵本身转置一下。它不依赖 $\mathbf{x}$，因为 $\mathbf{z}$ 对 $\mathbf{x}$ 是线性的，每个「动一点」的比例处处相同。下面用 $d = 2$、$V = 3$ 的小例子把它摆出来，行列对应关系靠位置对齐：

有了 Jacobian，第一章的那句话可以写第三遍。输入的变化是一个向量 $d\mathbf{x}$，输出的变化也是一个向量 $d\mathbf{z}$，每个分量 $dz_j$ 是它那一行和 $d\mathbf{x}$ 的点积，把 $V$ 个点积一起写就是矩阵乘向量：

$$d\mathbf{z} = J\,d\mathbf{x}$$

和 $dy = f'(x)\,dx$、$df = \nabla f \cdot d\mathbf{x}$ 放在一起看：三句话是同一句话，「倍数」依次是一个数、一个向量、一个矩阵。这一步之后不再需要新的概念，剩下的全是「某个具体运算的 Jacobian 长什么样」。

逐元素运算：对角 Jacobian

FFN 里 Swish 作用在长度为 $d_{ff}$ 的向量 $\mathbf{a}$ 上，得到同样长度的 $\mathbf{h}$，$h_i = \mathrm{Swish}(a_i)$。按定义，它的 Jacobian 是 $d_{ff} \times d_{ff}$ 个问题的答案：$a_i$ 动一点，$h_j$ 动多少？

绝大多数问题的答案是零。$h_j$ 只由 $a_j$ 算出来，和 $a_i$（$i \neq j$）没有关系，所以 $\dfrac{\partial h_j}{\partial a_i} = 0$。只有 $i = j$ 时答案不是零，就是上一章复习过的标量导数 $\mathrm{Swish}'(a_j)$。于是 Jacobian 只有对角线上有东西：

$$\frac{\partial \mathbf{h}}{\partial \mathbf{a}} = \begin{bmatrix} \mathrm{Swish}'(a_1) & 0 & \cdots & 0 \\ 0 & \mathrm{Swish}'(a_2) & \cdots & 0 \\ \vdots & & \ddots & \vdots \\ 0 & 0 & \cdots & \mathrm{Swish}'(a_{d_{ff}}) \end{bmatrix} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)$$

$\mathrm{diag}(\mathbf{v})$ 表示把向量 $\mathbf{v}$ 放到对角线上的方阵。任何「对每个分量各自做一件事」的运算都是这样，不管这件事是 sigmoid、指数还是平方。这一类运算叫逐元素运算，它们的 Jacobian 永远是对角矩阵，对角线上是对应的标量导数。

两个向量之间的逐元素运算也一样。SwiGLU 中间那一步 $\mathbf{h} = \mathbf{a} \otimes \mathbf{b}$，$h_i = a_i b_i$。对 $\mathbf{a}$ 求导，把 $\mathbf{b}$ 当常数，对角线上是 $b_i$；对 $\mathbf{b}$ 求导同理：

$$\frac{\partial (\mathbf{a} \otimes \mathbf{b})}{\partial \mathbf{a}} = \mathrm{diag}(\mathbf{b}),\qquad \frac{\partial (\mathbf{a} \otimes \mathbf{b})}{\partial \mathbf{b}} = \mathrm{diag}(\mathbf{a})$$

残差相加 $\mathbf{y} = \mathbf{x} + \mathbf{h}$ 是最简单的一种，对角线上全是 $1$，Jacobian 是单位矩阵 $I$。attention 分数除以 $\sqrt{d_h}$ 是乘常数，Jacobian 是 $\dfrac{1}{\sqrt{d_h}} I$。

模型里只有一个常见运算的 Jacobian 不是对角的、也不是权重矩阵：softmax。它的每个输出 $p_j = e^{s_j} / \sum_k e^{s_k}$ 依赖全部输入，因为分母里有所有的 $s_k$。它的 Jacobian 会在「每个算子一条反向规则」那一章单独算。

求和与平均

损失是 $T$ 个位置各自的损失取平均：$L = \dfrac{1}{T}\sum_{t=1}^{T} \ell_t$。这是一个「向量进、标量出」的运算，它的导数是一个梯度（一行），每个分量回答「$\ell_t$ 动一点，$L$ 动多少」：

$$\frac{\partial L}{\partial \ell_t} = \frac{1}{T},\qquad \frac{\partial L}{\partial \mathbf{\ell}} = \Big[\frac{1}{T}\ \ \frac{1}{T}\ \cdots\ \frac{1}{T}\Big]$$

不取平均、直接求和的话，每个分量是 $1$。softmax 的分母 $\sum_k e^{s_k}$ 也是一次求和，只是求和之前每一项先经过了指数函数，这就需要下一章的链式法则。

链式法则

到目前为止，每条规则都只管一个运算。模型是几十层运算套在一起，损失对最里面一个权重的导数要穿过全部这些层。链式法则说的就是穿过一层时该怎么办。它有三个版本，一个比一个一般，模型里三个都用到。

单变量：外层乘内层

先看一个数进、一个数出、中间套了一层的情形。取 FFN gate 分支的一个分量：先算 $a = x\,w$，再算 $h = \mathrm{Swish}(a)$。问：$x$ 动一点，$h$ 动多少？

分两步答。$x$ 动 $dx$，$a$ 动 $da = w\,dx$；$a$ 动 $da$，$h$ 动 $dh = \mathrm{Swish}'(a)\,da$。把第一步代进第二步：

$$dh = \mathrm{Swish}'(a)\cdot w\,dx,\qquad\text{也就是}\qquad \frac{dh}{dx} = \frac{dh}{da}\,\frac{da}{dx}$$

这就是单变量链式法则：外层的导数乘内层的导数。中间变量 $a$ 在两个分数里各出现一次，形式上像是约掉了，实际上它是把「一层」和「另一层」接起来的地方。写导数的时候建议把中间变量明确写出来，不要写成 $f'(g(x))\,g'(x)$，那样容易弄错是对谁求导。

套多少层都一样。$L$ 依赖 $p$，$p$ 依赖 $s$，$s$ 依赖 $w$，那么 $\dfrac{dL}{dw} = \dfrac{dL}{dp}\dfrac{dp}{ds}\dfrac{ds}{dw}$。反向传播的名字就来自这个式子：从最外层的 $L$ 开始，一层一层往里乘。

多条路径：相加

上面的情形里 $x$ 只通过 $a$ 影响 $h$，是一条路。残差连接不是这样：$y = x + g(x)$，$x$ 通过两条路影响 $y$，一条直接，一条经过 $g$。

答案是把每条路的贡献加起来。直接那条路的贡献是 $1 \cdot dx$，经过 $g$ 那条路的贡献是 $g'(x)\,dx$：

$$\frac{dy}{dx} = 1 + g'(x)$$

一般地说：$x$ 通过 $u_1, u_2, \ldots$ 几个中间量影响 $y$，那么

$$\frac{dy}{dx} = \sum_k \frac{\partial y}{\partial u_k}\,\frac{du_k}{dx}$$

每条路径上用一次「外层乘内层」，路径之间相加。上一章 $df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy$ 里的加号，也是这个加号。

模型里有三处要用到它。残差连接：每一层的输入既直接传到输出，又经过子层。GQA 里共用的 K、V 权重：一组 $W_K$ 被 $n_h / n_{kv}$ 个 query head 使用，损失对它的导数是每个 head 传回来的那一份相加。Embedding：同一个 token 在序列里出现几次，它那一行 $E$ 就被用了几次，导数是几次相加。

向量：Jacobian 相乘

把两个版本合起来，就得到向量版本。设 $\mathbf{a} = \mathbf{x}W$（$d$ 进、$d_{ff}$ 出），$\mathbf{h} = \mathrm{Swish}(\mathbf{a})$（$d_{ff}$ 进、$d_{ff}$ 出）。问 $\dfrac{\partial \mathbf{h}}{\partial \mathbf{x}}$，也就是回答 $d_{ff} \times d$ 个问题：$x_i$ 动一点，$h_j$ 动多少？

$x_i$ 不直接影响 $h_j$，它先影响 $a_1, a_2, \ldots, a_{d_{ff}}$，每个 $a_k$ 再影响 $h_j$。这是多条路径，每条路径上外层乘内层，然后相加：

$$\frac{\partial h_j}{\partial x_i} = \sum_k \frac{\partial h_j}{\partial a_k}\,\frac{\partial a_k}{\partial x_i}$$

右边这个「对 $k$ 求和的两项乘积」正是矩阵乘法的定义：第一个矩阵的第 $j$ 行乘第二个矩阵的第 $i$ 列。所以整个 Jacobian 是两个 Jacobian 的乘积：

$$\frac{\partial \mathbf{h}}{\partial \mathbf{x}} = \frac{\partial \mathbf{h}}{\partial \mathbf{a}}\,\frac{\partial \mathbf{a}}{\partial \mathbf{x}} = \mathrm{diag}\big(\mathrm{Swish}'(\mathbf{a})\big)\; W^{T}$$

形状检查：$d_{ff} \times d_{ff}$ 乘 $d_{ff} \times d$ 得到 $d_{ff} \times d$，正好是 $d_{ff}$ 个输出、$d$ 个输入。这个检查每次都要做，形状对不上一定是哪里写错了。

这就是向量链式法则：外层的 Jacobian 乘内层的 Jacobian，顺序和单变量版本一样，从外往里写。它和单变量版本是同一个式子，「乘」换成了矩阵乘法，「多条路径相加」被矩阵乘法里的求和自动包含了。

反向传播从不构造 Jacobian

照上面的写法，损失对 $W_{gate}$ 的导数要先算出 $\dfrac{\partial \mathbf{h}}{\partial W_{gate}}$，这是第一章形状表里标红的三维数组，$d_{ff} \times d \times d_{ff}$ 个数。对 $d_{ff} = 14336$、$d = 4096$ 来说，这个数组比整个模型还大。反向传播不这样做。

关键在于最终要的东西是 $\dfrac{\partial L}{\partial(\cdot)}$，而 $L$ 是一个数。看损失对 $\mathbf{a}$ 的导数：$a_k$ 不直接影响 $L$，它先影响 $h_1, h_2, \ldots$，再由每个 $h_j$ 影响 $L$。多条路径相加：

$$\frac{\partial L}{\partial a_k} = \sum_j \frac{\partial L}{\partial h_j}\,\frac{\partial h_j}{\partial a_k} = \sum_j \frac{\partial L}{\partial h_j}\,J_{jk}$$

把 $\dfrac{\partial L}{\partial \mathbf{h}}$ 看成一个行向量 $\mathbf{g}$（长度 $d_{ff}$），上式就是行向量乘矩阵：

$$\frac{\partial L}{\partial \mathbf{a}} = \mathbf{g}\,J,\qquad \mathbf{g} = \frac{\partial L}{\partial \mathbf{h}}$$

结果还是一个行向量，长度和 $\mathbf{a}$ 相同。这个运算叫 vector-Jacobian product。反向传播每经过一个运算，做的就是这一件事：拿到损失对这个运算输出的导数 $\mathbf{g}$，算出损失对它输入的导数 $\mathbf{g}J$，再往前传。自始至终传的都是和数据同形状的向量，从不出现比数据大的东西。

而且 $\mathbf{g}J$ 几乎从不需要真的把 $J$ 写出来。看模型里的两种 Jacobian：

对角 Jacobian。$J = \mathrm{diag}(\mathbf{v})$ 时，$\mathbf{g}J$ 的第 $k$ 个分量是 $g_k v_k$，也就是逐元素相乘：

$$\mathbf{g}\,\mathrm{diag}(\mathbf{v}) = \mathbf{g} \otimes \mathbf{v}$$

Swish 的反向就是 $\mathbf{g} \otimes \mathrm{Swish}'(\mathbf{a})$，一个 $d_{ff}$ 长度的逐元素乘，不是一个 $d_{ff} \times d_{ff}$ 的矩阵乘。

矩阵乘法的 Jacobian。$\mathbf{a} = \mathbf{x}W$ 时 $J = W^T$，于是

$$\frac{\partial L}{\partial \mathbf{x}} = \mathbf{g}\,W^{T}$$

这是一次普通的矩阵乘法。损失对 $W$ 的导数也不需要那个三维数组：$W_{ki}$ 只出现在 $a_i = \sum_k x_k W_{ki}$ 这一个输出里，所以只有一条路径，

$$\frac{\partial L}{\partial W_{ki}} = \frac{\partial L}{\partial a_i}\,\frac{\partial a_i}{\partial W_{ki}} = g_i\,x_k,\qquad\text{合起来}\qquad \frac{\partial L}{\partial W} = \mathbf{x}^{T}\mathbf{g}$$

$\mathbf{x}^T$ 是 $d \times 1$，$\mathbf{g}$ 是 $1 \times d_{ff}$，乘出来 $d \times d_{ff}$，和 $W$ 同形状。序列有 $T$ 个位置时，$X$ 是 $T \times d$，$G$ 是 $T \times d_{ff}$，$\dfrac{\partial L}{\partial W} = X^T G$，$T$ 个位置的贡献在矩阵乘法里自动相加了，这又是「多条路径相加」。

到这里，第一章形状表下面那个承诺兑现了：三维数组出现在中间，但反向传播绕开了它，代价只是几次和前向同样大小的矩阵乘法。下一章把模型里每个运算的这一条反向规则逐个列出来。

每个算子一条反向规则

上一章的结论可以写成一个固定格式。对图里的每一个方框：前向算出 输出 $= f(\text{输入})$；反向拿到 $G = \dfrac{\partial L}{\partial\,\text{输出}}$，它和输出同形状；返回 $\dfrac{\partial L}{\partial\,\text{输入}}$，和输入同形状；方框里有权重的，再返回 $\dfrac{\partial L}{\partial W}$，和 $W$ 同形状。自动微分系统就是这样一张表：每种运算登记一条反向规则，backward() 按前向的相反顺序逐条调用。

下面按图里出现的运算逐个写出这条规则。记号：大写 $X$、$G$ 是 $T$ 个位置堆成的矩阵，$X$ 是 $T \times d$；小写 $\mathbf{x}$ 是其中一行。每条规则后面都做一次形状检查。

矩阵乘法

前向：$Z = XW$，$X$ 是 $T \times d$，$W$ 是 $d \times m$，$Z$ 是 $T \times m$。反向拿到 $G$（$T \times m$）：

$$\frac{\partial L}{\partial X} = G\,W^{T},\qquad \frac{\partial L}{\partial W} = X^{T}G$$

形状检查$G W^T$：$T \times m$ 乘 $m \times d$ 得 $T \times d$，和 $X$ 相同。$X^T G$：$d \times T$ 乘 $T \times m$ 得 $d \times m$，和 $W$ 相同。

上一章已经对一行推过，$T$ 行堆在一起时，$X^T G$ 把 $T$ 个位置对 $W$ 的贡献加在了一起。这一条覆盖图里所有带权重的方框：$W_Q$、$W_K$、$W_V$、$W_O$、$W_{gate}$、$W_{up}$、$W_{down}$、$W_{out}$。attention 里的 $QK^T$ 和 $PV$ 也是矩阵乘法，只是两边都是 activation，没有权重：对 $S = QK^T$，把 $K^T$ 放在 $W$ 的位置，得到 $\dfrac{\partial L}{\partial Q} = G K$，$\dfrac{\partial L}{\partial K} = G^T Q$。

Embedding

前向：第 $t$ 个位置取出 $E$ 的第 $\text{tok}_t$ 行，$X_0[t] = E[\text{tok}_t]$。这等价于一个 one-hot 矩阵（$T \times V$，每行只有一个 1）乘 $E$，所以它是矩阵乘法的特例。

反向拿到 $G$（$T \times d$）：$\dfrac{\partial L}{\partial E}$ 从全零的 $V \times d$ 矩阵开始，把 $G$ 的第 $t$ 行加到第 $\text{tok}_t$ 行上。同一个 token 在序列里出现几次，它那一行就被加几次，这是「多条路径相加」。token 编号是整数，不对它求导，反向到这里为止。

逐元素运算与残差

这几条都来自对角 Jacobian，反向全是逐元素相乘，不出现矩阵乘法。

逐元素函数 $H = \mathrm{Swish}(A)$：$\dfrac{\partial L}{\partial A} = G \otimes \mathrm{Swish}'(A)$。sigmoid、指数、任何逐元素函数都一样，换成对应的标量导数。

逐元素乘 $H = A \otimes B$：$\dfrac{\partial L}{\partial A} = G \otimes B$，$\dfrac{\partial L}{\partial B} = G \otimes A$。

残差相加 $Y = X + H$：$\dfrac{\partial L}{\partial H} = G$，同时 $X$ 也拿到一份 $G$。$X$ 还通过子层影响 $Y$，那一条路传回来的导数要和这份 $G$ 相加，最终 $\dfrac{\partial L}{\partial X} = G + (\text{子层传回的})$。反向传播先把 $G$ 交给子层算完，再做这个加法。

常数缩放 $S = S' / \sqrt{d_h}$：$\dfrac{\partial L}{\partial S'} = G / \sqrt{d_h}$。causal mask 是把常数 $-\infty$ 加到被遮住的位置，它没有参数，被遮住的位置 softmax 输出为零，导数也为零，反向什么都不用做。

softmax

对一行 $\mathbf{s}$（长度 $n$）：$p_j = \dfrac{e^{s_j}}{\sum_k e^{s_k}}$。每个 $p_j$ 依赖全部 $s_i$，Jacobian 不是对角的。用商法则算 $\dfrac{\partial p_j}{\partial s_i}$，分子 $e^{s_j}$ 只在 $i = j$ 时依赖 $s_i$，分母对每个 $s_i$ 的导数是 $e^{s_i}$：

$$\frac{\partial p_j}{\partial s_i} = \frac{[i=j]\,e^{s_j}\sum_k e^{s_k} - e^{s_j}e^{s_i}}{\big(\sum_k e^{s_k}\big)^2} = [i=j]\,p_j - p_j p_i$$

$[i = j]$ 在 $i = j$ 时为 1，否则为 0。整个 Jacobian 是 $\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$：一个对角矩阵减去一个秩为 1 的矩阵。反向拿到 $\mathbf{g}$，按 $\mathbf{g}J$ 算：

$$\frac{\partial L}{\partial \mathbf{s}} = \mathbf{g}\,\big(\mathrm{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T\big) = \mathbf{g} \otimes \mathbf{p} - (\mathbf{g}\cdot\mathbf{p})\,\mathbf{p} = \mathbf{p} \otimes \big(\mathbf{g} - (\mathbf{g}\cdot\mathbf{p})\big)$$

最后一个式子里 $\mathbf{g}\cdot\mathbf{p}$ 是一个数，从 $\mathbf{g}$ 的每个分量里减去它。这是全文唯一一个非对角、也不是权重矩阵的 Jacobian，但反向仍然不用把它写出来：一次点积、一次减法、一次逐元素乘，代价和 $\mathbf{p}$ 的长度成正比。attention 里对 $T \times T$ 的分数矩阵逐行做这件事，LM head 后面对 $T \times V$ 的 logits 逐行做这件事。

cross-entropy

前向：第 $t$ 个位置的损失 $\ell_t = -\ln p_{t,\,y_t}$，$y_t$ 是目标 token；$L = \dfrac{1}{T}\sum_t \ell_t$。

反向：$L$ 对 $p_{t,j}$ 的导数，只有 $j = y_t$ 那一项不为零，用对数规则和 $1/T$：

$$\frac{\partial L}{\partial p_{t,j}} = \begin{cases} -\dfrac{1}{T\,p_{t,y_t}} & j = y_t \\[6pt] 0 & j \neq y_t \end{cases}$$

把它作为 $\mathbf{g}$ 代入 softmax 的反向规则。$\mathbf{g}$ 只有一个非零分量，所以 $\mathbf{g}\cdot\mathbf{p} = -\dfrac{1}{T}$，于是 $\mathbf{p} \otimes (\mathbf{g} - (\mathbf{g}\cdot\mathbf{p}))$ 的第 $j$ 个分量是 $p_{t,j}\big(g_j + \frac{1}{T}\big)$。$j = y_t$ 时是 $\frac{1}{T}(p_{t,y_t} - 1)$，其余是 $\frac{1}{T}p_{t,j}$。合起来：

$$\frac{\partial L}{\partial \mathbf{s}_t} = \frac{1}{T}\big(\mathbf{p}_t - \mathbf{y}_t\big),\qquad \frac{\partial L}{\partial S} = \frac{1}{T}\,(P - Y)$$

$\mathbf{y}_t$ 是目标 token 的 one-hot 向量，$Y$ 是它们堆成的 $T \times V$ 矩阵。这是训练里最常被引用的一个结果：损失对 logits 的导数就是预测分布减去真实分布。它说明 softmax 和 cross-entropy 在实现里总是合成一个算子的原因：合起来的反向规则比各自的都简单。

GQA attention

attention 没有新的规则，它是上面几条的组合。对一个 query head $i$，它所在的组是 $j$，前向依次是：

  1. 三次矩阵乘法：$Q_i = XW_Q^{(i)}$，$K_j = XW_K^{(j)}$，$V_j = XW_V^{(j)}$。
  2. 矩阵乘法加常数缩放加 mask：$S_i = Q_iK_j^T/\sqrt{d_h} + M$。
  3. 逐行 softmax：$P_i = \mathrm{softmax}(S_i)$。
  4. 矩阵乘法：$A_i = P_iV_j$。
  5. 拼接所有 head，矩阵乘法：$A = [A_1 \cdots A_{n_h}]\,W_O$。

反向按相反顺序：$W_O$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial W_O}$，并把 $G$ 拆回每个 head 的 $\dfrac{\partial L}{\partial A_i}$；$A_i = P_iV_j$ 给出 $\dfrac{\partial L}{\partial P_i}$ 和 $V_j$ 收到的一份；softmax 的反向给出 $\dfrac{\partial L}{\partial S_i}$；除以 $\sqrt{d_h}$；$S_i$ 那次矩阵乘法给出 $\dfrac{\partial L}{\partial Q_i}$ 和 $K_j$ 收到的一份。

需要相加的地方有两处。第一，$K_j$ 和 $V_j$ 被同一组的 $n_h / n_{kv}$ 个 head 共用，每个 head 都传回来一份，$\dfrac{\partial L}{\partial K_j}$ 是这些份数之和，之后才用矩阵乘法规则得到 $\dfrac{\partial L}{\partial W_K^{(j)}} = X^T\dfrac{\partial L}{\partial K_j}$。第二，$X$ 同时进入了 $Q$、$K$、$V$ 三次矩阵乘法，$\dfrac{\partial L}{\partial X}$ 是三条路径之和，再加上残差那一份。

FP32 到 BF16 的转换

前向：$W_{\text{bf16}} = \mathrm{round}(W_{\text{fp32}})$，把每个数舍入到 BF16 能表示的最近的值。这一步在图里的每个带权重的方框内部，矩阵乘法之前。

按定义，这个函数是阶梯状的：在几乎所有点导数为零，在跳变点没有导数。照规则算，梯度到这里就断了，权重永远不会更新。所以框架不按定义算，而是登记一条约定：

$$\frac{\partial L}{\partial W_{\text{fp32}}} := \frac{\partial L}{\partial W_{\text{bf16}}}\ \text{转回 FP32}$$

也就是把舍入当作恒等运算，导数原样通过。这是一个决定，不是一个定理。它能用的理由是舍入误差远小于一次更新的幅度，忽略它不影响下降的方向。优化器随后在 FP32 的主权重上做更新，下一步前向再舍入一次。activation 一侧也一样：矩阵乘法在 BF16 里做，反向传回的 $G$ 是 BF16，$X^T G$ 算出的权重导数累加到 FP32 里。这就是引言里说的「反向传播必须经过它」：它不产生任何数学，但每一步都在。

把整个模型串起来

规则都有了，剩下的是顺序。反向传播从 $L$ 出发，沿图里的箭头反方向走，每经过一个方框调用它那条规则，每到一个圆角框把各条路径传回来的导数相加。下面按步骤走一遍，图上高亮的是当前所在的位置。

回头看第一章的三件事：最上面是整数，最下面是 scalar，中间全是矩阵；要求的是 scalar 对每个权重矩阵的导数；求导沿箭头反方向逐层往回传。现在每一句都有了具体内容。
