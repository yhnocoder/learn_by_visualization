  • float.exposed — Bartosz Ciechanowski. Interactive bit-level explorer for fp16 / bf16 / fp32 / fp64; the layout and interaction design of this page are borrowed from it.
  • jax-ml/ml_dtypes — Reference implementation of fp4 / fp6 / fp8 formats used to verify every encoding and rounding rule on this page.

  • IEEE 754-2019 — Standard for binary16 / binary32 / binary64 encoding and rounding.
