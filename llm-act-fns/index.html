01引言

激活函数在 LLM 里的位置

一个 decoder block 由注意力和前馈网络（FFN）两部分组成。激活函数出现在 FFN 中间：输入先被升维，过一个逐元素的非线性，再被降回来（注意力里的 softmax 严格来说也是非线性，但它的角色是归一化权重，不是我们平时说的「激活函数」）。写成最朴素的形式就是

$$\mathrm{FFN}(x) = \phi(xW_1 + b_1)\,W_2 + b_2,\qquad W_1\in\mathbb{R}^{d\times d_{ff}},\; W_2\in\mathbb{R}^{d_{ff}\times d}.$$

这一层通常占一个 dense 模型三分之二的参数，对于 MoE 模型，更是包含了几乎全部的参数。所以对激活函数的任何要求，最终都要回到三件事上：在同等算力下 loss 能不能更低；在几百亿到几万亿参数的规模下训练会不会不稳定；以及推理时这个逐元素操作能不能以轻量的方式融合进 GEMM 的 epilogue（对矩阵乘法结果执行逐元素操作的阶段）中，不额外占带宽。

2017 年的原始 Transformer 用 ReLU，2018 年 BERT 和 GPT 换成 GELU，2020 年 Shazeer 证明门控形式的 GLU 能在同参数量下压低 loss ，之后 PaLM 和 Llama 把 SwiGLU 变成了事实标准。2025 到 2026 年的变化则来自另一个方向：模型大到一定程度之后，GLU 的乘积无界成了训练稳定性的隐患，于是 gpt-oss、DeepSeek-V4、Kimi K3 各自给它加了上界（clamp 或 soft-capping）；与此同时 NVIDIA 的 Nemotron 用回了 Squared ReLU。综合这些变化，激活函数的选择其实是在「表达力、稳定性、稀疏性、内核效率」四个目标之间取平衡，下面每一节都会回到这四个词。

一个神经元收到的是什么

上面的 FFN 公式对一个 token 的表示 $x\in\mathbb{R}^{d}$ 进行计算。中间层有 $d_{ff}$ 个神经元，第 $i$ 个神经元收到的数是

$$z_i = x\,w_i + b_i ,$$

其中 $w_i$ 是 $W_1$ 的第 $i$ 列，$b_i$ 是 $b_1$ 的第 $i$ 个分量。$z_i$ 称为预激活值（pre-activation），它是 $x$ 在方向 $w_i$ 上的投影加上一个偏置，是一个实数。激活函数 $\phi$ 逐元素作用，所以它对第 $i$ 个神经元的计算只用到 $z_i$ 这一个数，不用到 $x$ 的其他分量，也不用到同一层其他神经元的 $z_j$。一个长度为 $T$ 的序列经过这一层时，会产生 $T\times d_{ff}$ 个这样的实数，$\phi$ 对每一个都独立地计算一次。

本文的曲线图把激活函数记作 $f$，横轴记作 $x$。对第 $i$ 个神经元而言，图中的 $x$ 就是它的预激活值 $z_i$，$f$ 就是公式里的 $\phi$。每张图都有 $f(x)$ 和 $f'(x)$ 两个面板，它们分别对应下面两件事。

$f(x)$ 决定这个神经元在前向传播中贡献多少。FFN 的输出是

$$\mathrm{FFN}(x)=\sum_{i=1}^{d_{ff}} f(z_i)\,W_2[i,:]+b_2 ,$$

也就是把 $W_2$ 的每一行按 $f(z_i)$ 加权后相加。$f(z_i)=0$ 时第 $i$ 行完全不参与，$f(z_i)$ 越大这一行的权重越大，$f(z_i)$ 为负时这一行以相反的方向参与。所以，看 $f(x)$ 面板的纵轴，就是在看「当预激活值取某个数时，这个神经元对应的 $W_2$ 行被放大多少倍」。

$f'(x)$ 决定这个神经元在反向传播中传回多少梯度。记 loss 对 FFN 输出的梯度为 $\delta$。因为 $f$ 逐元素作用，它的 Jacobian 是对角矩阵，梯度传到 $z_i$ 时只乘一个标量 $f'(z_i)$：

$$\frac{\partial L}{\partial z_i}=\bigl(\delta\,W_2[i,:]^{\top}\bigr)\,f'(z_i),\qquad \frac{\partial L}{\partial w_i}=x^{\top}\frac{\partial L}{\partial z_i},\qquad \frac{\partial L}{\partial x}=\sum_{i=1}^{d_{ff}}\frac{\partial L}{\partial z_i}\,w_i^{\top}.$$

$f'(z_i)$ 同时控制两条路径：一条是流向本神经元参数 $w_i$ 和 $b_i$ 的梯度，决定这个神经元是否会因这个 token 而更新；另一条是经过 $w_i$ 流回 $x$ 的梯度，决定这个神经元是否把误差信号传给更靠前的层。$f'(z_i)=0$ 时两条路径都被切断；$f'(z_i)$ 大于 1 时梯度被放大；$f'(z_i)$ 为负时梯度的符号被翻转。所以 $f'(x)$ 面板要和 $f(x)$ 面板一起看：前者说明这个神经元现在贡献多少，后者说明它还能不能被修正。

读图时要看的四个要素

常见情况下，预激活值 $z_i$ 在训练中的分布大致以零为中心：多数落在原点附近的一个有限范围内，两侧各有一部分落在较远处。把横轴按此分成四段，每一段上都有一批神经元。在某一段上要问什么问题，取决于落在这一段的神经元会经历什么。

要素一：负半轴远端（$x\to-\infty$）。落在这里的神经元收到的是与 $w_i$ 方向相反的强输入，按设计意图它们不应当响应。要问的第一个问题是 $f(x)$ 是否严格为零，还是只是趋近零。严格为零时，这个神经元对应的 $W_2$ 行完全不参与求和，推理时可以跳过这一行的计算，这是激活稀疏性的前提；只是趋近零时，仍有一个很小的输出通过，不能跳过。如果 $f(x)$ 趋近的不是零而是某个非零常数，还要考虑这个常数会以固定比例把 $W_2$ 的这一行加进输出。第二个问题是 $f'(x)$ 是否为零。为零时，落在这里的神经元不会因这个 token 得到任何更新；如果一个神经元对多数 token 都落在这里，它就不再更新，也没有机会回到别的区域。$f'(x)$ 很小但非零时，更新仍在进行，只是缓慢。所以在这一段要看 $f(x)$ 的极限值、它趋近极限的快慢，以及 $f'(x)$ 是否严格为零。

要素二：零点（$x=0$）。初始化时预激活值集中在零附近，训练全程也始终有大量神经元落在这里，它是「响应」与「不响应」的分界。要问三个问题。$f(0)$ 是多少：输入为零时是否输出零；如果输出一个非零常数，这个常数与输入无关，会固定地加进 $W_2$ 的求和。$f'(0)$ 是多少：零附近的小扰动以多大比例通过，这决定训练初期这一层近似于什么样的线性映射，也决定用作门控系数时零输入对应的信号被乘以多少。$f$ 在原点是否可导：如果不可导，数学上这一点的导数没有定义，实现时必须约定一个值，并且 $f'(x)$ 在这里跳变，一个神经元的预激活值从零的一侧跨到另一侧时，它收到的梯度会突然改变。

要素三：过渡区。这是 $f$ 从负半轴的行为切换到正半轴的行为所经过的输入范围，也是不同激活函数的曲线差异最大的地方。落在这里的神经元处于部分响应的状态，它们的输出和梯度都对输入的变化敏感。要问的问题是：过渡有多宽，宽度决定了有多少神经元处于部分响应的状态，过渡集中在一个点上时函数接近硬开关，过渡很宽时多数神经元都在部分响应；$f'(x)$ 是否连续，不连续意味着神经元跨过某个输入值时梯度跳变；$f$ 是否单调，$f'(x)$ 是否越过零或超过 1，如果 $f$ 在这一段有一个最低点，那么最低点左侧有一段区间 $f'(x)$ 为负，落在这里的神经元收到的梯度符号被翻转，如果 $f'(x)$ 超过 1，落在这里的神经元收到的梯度被放大。图中的色带标出过渡区的范围，色带的定义随函数改变，见各图图注。

要素四：正半轴远端（$x\to+\infty$）。落在这里的神经元收到与 $w_i$ 方向一致的强输入，是完全响应的神经元，也是数值幅度最大的地方；模型规模增大之后，训练不稳定往往首先出现在这里。要问的第一个问题是 $f(x)$ 有没有上界。没有上界时，$W_2$ 的求和中可能出现很大的项，需要考虑数值范围和后续归一化能否承受；有上界时，不同的强输入给出近似相同的输出，它们之间的差异被压缩。第二个问题是 $f(x)$ 以什么速度增长：与 $x$ 同速、比 $x$ 快，还是趋于停止。第三个问题是 $f'(x)$ 的极限：趋近一个常数，意味着强输入的梯度按固定比例通过；趋近零，意味着强输入几乎收不到梯度；没有上界，意味着梯度随输入增大而增大。图中的虚线表示极限行为，不表示饱和从某个固定位置开始。

阅读约定

本文的 $\sigma(x)=\dfrac{1}{1+e^{-x}}$ 表示 logistic sigmoid，$\Phi(x)$ 表示标准正态分布的累积分布函数，$\odot$ 表示逐元素乘。

02总览

比较各函数的输出、导数和极限行为。

Logistic：把输入映射到 0 与 1 之间

$$\sigma(x)=\frac{1}{1+e^{-x}},\qquad \sigma'(x)=\sigma(x)\bigl(1-\sigma(x)\bigr).$$

$\Phi(x)$：标准正态分布的累积概率

$$\Phi(x)=\int_{-\infty}^{x}\frac{e^{-t^2/2}}{\sqrt{2\pi}}\,dt,\qquad \Phi'(x)=\varphi(x)=\frac{e^{-x^2/2}}{\sqrt{2\pi}}.$$

03Sigmoid 与 Tanh：门控与 soft-capping

它们较少直接用作现代 LLM 的 FFN 激活函数，但常用于门控和限制输出范围。

$$\begin{aligned} \sigma(x)&=\frac{1}{1+e^{-x}},&\qquad \sigma'(x)&=\sigma(x)\bigl(1-\sigma(x)\bigr)\le\tfrac14;\\[8pt] \tanh(x)&=2\sigma(2x)-1,&\qquad \tanh'(x)&=1-\tanh^2(x)\le 1. \end{aligned}$$

在现代模型中，sigmoid 常用于门控：SiLU 本身就是 $x\,\sigma(x)$，DeepSeek-V3 的 MoE 路由用 sigmoid 给专家打分，Qwen3-Next 的 gated attention 在注意力输出后乘一个 sigmoid gate，Mamba 和 Gated DeltaNet 的遗忘 gate 也都是 sigmoid。它有界、单调、输出天然落在 $(0,1)$，这些性质便于将它用作乘法系数。但接近 0 或 1 时，梯度仍会因饱和而减小。

tanh 也用于 soft-capping。任何一个无界量 $z$ 都可以写成 $c\cdot\tanh(z/c)$，这样在 $|z|\ll c$ 时几乎是恒等映射，导数接近 1；在 $|z|\gg c$ 时被平滑地压到 $\pm c$ 以内。Gemma 2 用它处理 logits，Gemma 3 一度去掉，Gemma 4 又把最终 logits 的 soft-capping 加了回来（final_logit_softcapping: 30.0）；Kimi K3 用它处理 GLU 的两个分支，这个思路我们在第 08 节还会展开。相比 hard clamp，tanh soft-capping 的好处是导数处处连续，饱和区域的梯度不是直接归零，而是按 $1-\tanh^2$ 平滑衰减，在有限输入下，数学上的导数仍非零。

04ReLU：计算开销与激活稀疏性

它计算开销小，能让 FFN 的中间层出现大量精确为零的输出。这两点在 2024 年之后重新变得重要。

$$\mathrm{ReLU}(x)=\max(0,x),\qquad \mathrm{ReLU}'(x)=\mathbb{1}[x>0].$$

原始 Transformer 用的就是 ReLU，被 GELU 取代的直接原因是在同等设置下 loss 略高一些，间接原因是它在原点不光滑、负半轴梯度恒为零，训练早期一旦某个通道的激活值的输入整体偏负，它就再也不会被更新（具体参考：dead ReLU）。对于 2018 年在几亿参数规模上做预训练的人来说，换成 GELU 收益虽小但稳定，于是 ReLU 就退出了主流 LLM。

稀疏推理研究重新关注了 ReLU。Apple 在「ReLU Strikes Back」这篇工作里指出，如果 FFN 用 ReLU，那么中间层的输出在大多数 token 上有九成以上是精确的零，而每个零对应着 $W_2$ 中一整行不需要读取、不需要参与乘法的权重。对于内存带宽受限的推理场景（尤其是端侧和 CPU offloading），这意味着 FFN 的实际计算量可以降到原来的三分之一左右，而且用 ReLU 重新微调一个 GELU 或 SiLU 模型（论文称之为 ReLUfication，即将激活函数替换为 ReLU 后继续训练） 损失的精度并不多。后续的 TurboSparse 将这一方法扩展到门控结构，提出 dReLU：对 gate projection 和 up projection 的输出分别应用 ReLU，再逐元素相乘，

$$\mathrm{dReLU}(x)=\mathrm{ReLU}(xW_g)\odot\mathrm{ReLU}(xW_u),$$

在 Mixtral 这类模型上得到了接近 90% 的稀疏度。SiLU 和 GELU 的输出通常非零；ReLU 则在整个负半轴上输出严格为零，支持按零值跳过计算。

那为什么 2026 年最强的开源模型依然不用 ReLU？因为它们的瓶颈是训练时的 loss 和稳定性，不是端侧带宽；而 ReLU 在这两方面的劣势并没有消失。

05GELU：定义、导数与常用近似

把 dropout 和 ReLU 合并成一个确定性的函数。

$$\mathrm{GELU}(x)=x\,\Phi(x)=x\int_{-\infty}^{x}\frac{1}{\sqrt{2\pi}}e^{-t^2/2}\,dt,\qquad \mathrm{GELU}'(x)=\Phi(x)+x\,\varphi(x),$$

其中 $\varphi$ 是标准正态密度。Hendrycks 和 Gimpel 的出发点是：ReLU 是把输入乘以 $\mathbb{1}[x>0]$，dropout 是把输入乘以一个伯努利随机变量，那么不妨把这个随机变量的概率设成与输入相关的 $\Phi(x)$，再对随机性取期望，得到的就是 $x\Phi(x)$。这样输入越大越可能被「保留」，越小越可能被「丢弃」，而整个过程是确定性且光滑的。

展开了解：为什么期望恰好是 $x\Phi(x)$？

这里的随机操作只有两个结果：保留输入 $x$，或者把它置为 $0$。设 $B$ 是一个取值为 $0$ 或 $1$ 的随机变量，并规定

$$P(B=1\mid x)=\Phi(x),\qquad P(B=0\mid x)=1-\Phi(x).$$

给定输入 $x$，输出就是 $xB$。对这次随机选择取期望：

$$\mathbb E[xB\mid x]=\underbrace{x\cdot\Phi(x)}_{\text{保留时的输出}\times\text{概率}}+\underbrace{0\cdot\bigl[1-\Phi(x)\bigr]}_{\text{置零时的输出}\times\text{概率}}=x\,\Phi(x).$$

例如，若某个输入的保留概率为 $0.8$，那么平均输出就是 $0.8x$。ReLU 对应 $P(B=1\mid x)=\mathbb{1}[x>0]$，dropout 对应 $P(B=1\mid x)=p$ 且与 $x$ 无关；GELU 把这个概率改成随 $x$ 单调增加的 $\Phi(x)$，再取期望，就得到确定性的 $x\Phi(x)$。

两个近似

$\Phi(x)$ 可以通过误差函数 $\mathrm{erf}$ 计算。相比 ReLU，它的数值求值更复杂，因此也常使用近似形式；实际性能收益取决于硬件和实现。

展开了解：erf 是什么，计算机怎样计算它？

误差函数（error function）的定义是

$$\operatorname{erf}(x)=\frac{2}{\sqrt{\pi}}\int_0^x e^{-t^2}\,dt.$$

它表示曲线 $e^{-t^2}$ 从 0 到 $x$ 的有符号面积，再乘一个固定系数。“误差”这个名字与正态分布中的误差概率有关，并不是指神经网络的 loss。

它与 $\Phi(x)$ 是同一种积分的不同写法。标准正态分布关于 0 对称，左半边面积为 $1/2$。先把积分拆在 0 处，再令 $u=t/\sqrt2$，就有

$$\begin{aligned} \Phi(x)&=\frac12+\frac{1}{\sqrt{2\pi}}\int_0^x e^{-t^2/2}\,dt\\[6pt] &=\frac12+\frac{1}{\sqrt\pi}\int_0^{x/\sqrt2}e^{-u^2}\,du\\[6pt] &=\frac12\left[1+\operatorname{erf}\left(\frac{x}{\sqrt2}\right)\right]. \end{aligned}$$

把积分写成 erf，并没有自动消除计算难度，实际求值通常依靠近似公式。数学库可以用多项式或两个多项式之比来逼近 erf，并按输入区间选择适合的公式，以控制误差。多项式又可以写成嵌套的乘加形式，例如

$$a_0+a_1x+a_2x^2+a_3x^3=a_0+x\bigl(a_1+x(a_2+xa_3)\bigr).$$

这样只需有限次运算就能得到近似值，无须每次把积分面积切成大量小块逐一相加。这里的多项式只是计算方式的示例，具体系数、次数和区间由实现及精度要求决定。NIST 的数值近似资料列出了 erf 的多项式和有理函数近似方法。

开销主要来自更多计算。ReLU 只需比较并选择，而 erf 的求值通常需要一组乘加及可能的区间判断等操作。FFN 的每个中间元素都要计算一次，大量重复后就可能影响速度；这并不意味着 erf 天然需要大量显存。tanh 近似能否更快，还要看硬件支持、精度和内核融合方式，不能只看公式长短。

一个是 tanh 近似：

$$\mathrm{GELU}_{\tanh}(x)=\tfrac12 x\bigl[1+\tanh u\bigr],\qquad u=\sqrt{\tfrac{2}{\pi}}\,(x+0.044715\,x^3),$$

它的导数由乘积法则给出，其中 $\tanh' u=1-\tanh^2 u$：

$$\mathrm{GELU}_{\tanh}'(x)=\tfrac12\bigl[1+\tanh u\bigr]+\tfrac12 x\,\bigl(1-\tanh^2 u\bigr)\,\sqrt{\tfrac{2}{\pi}}\,\bigl(1+0.134145\,x^2\bigr).$$

BERT、GPT-2 以及现在的 Gemma 系列用的都是它。另一个常被叫作 Quick GELU：

$$\begin{aligned}\mathrm{GELU}_{\text{quick}}(x)&=x\,\sigma(1.702x),\\ \mathrm{GELU}_{\text{quick}}'(x)&=\sigma(1.702x)\bigl[1+1.702\,x\,\bigl(1-\sigma(1.702x)\bigr)\bigr].\end{aligned}$$

系数 1.702 用来让 $\sigma(1.702x)$ 逼近 $\Phi(x)$。OpenAI 的 CLIP 用过，而 gpt-oss 的激活函数里那个 $\alpha=1.702$ 也是从这儿来的。

近似的存在带来一个工程的规则：训练用哪个版本，推理就必须用哪个版本。Gemma 刚开源时 Hugging Face 的实现用了精确 GELU，而官方权重是用 tanh 近似训的，两者在大多数位置只差万分之几，但一层层累积之后足以影响生成质量，最后是 transformers 专门加了 gelu_pytorch_tanh 才解决。做权重转换、写推理内核、做量化校准的时候，这是最常见的silent bug 之一。

06SiLU / Swish：输入与 sigmoid 的乘积

它的曲线与 GELU 接近，但只需要一次 sigmoid 和一次乘法。

$$\mathrm{Swish}_\beta(x)=x\,\sigma(\beta x),\qquad \mathrm{Swish}_\beta'(x)=\sigma(\beta x)\bigl[1+\beta x\bigl(1-\sigma(\beta x)\bigr)\bigr].$$

$\beta=1$ 的特例叫 SiLU（Sigmoid Linear Unit），最早由 Elfwing 等人在强化学习的语境下提出；Google 的 Ramachandran 等人用自动搜索重新发现了它，并把 $\beta$ 设为可学参数，取名 Swish。现在 LLM 里说 SiLU、Swish 基本指同一个东西，$\beta$ 也基本都固定为 1。

SiLU 的三个性质值得记住。第一，它是非单调的，在负半轴有一个局部最小值，这让网络可以输出小的负数而不是被截断，实践中这被认为对优化略有帮助。第二，它在原点附近近似线性，$\mathrm{SiLU}(x)\approx x/2 + x^2/4$，这意味着初始化时如果预激活值集中在零附近，FFN 在该输入范围内近似线性；训练稳定性还取决于初始化、归一化等设置。第三，它的导数只依赖 $\sigma(\beta x)$ 一个中间量，前向存下 $\sigma$ 值，反向就不需要重算任何超越函数，这一点可以减少反向传播中的重复计算，但保存中间值会占用显存。

它取代 GELU 的过程没有一篇决定性的论文，也受计算开销和实现方式影响：Shazeer 2020 的实验里 SwiGLU 和 GeGLU 的实验结果接近，而 SiLU 更轻量，PaLM 和 Llama 选了 SwiGLU，之后所有跟随 Llama 架构的模型也就沿用了下来。到 2026 年，SiLU 单独作为 FFN 激活的情况已经很少，它几乎总是用于 SwiGLU 的门控分支。

07GLU 家族：门控前馈网络

SwiGLU、GeGLU、ReGLU 的区别只是 gate 用什么函数；重要的是「gate 乘以线性分支」这个结构本身。

$$\mathrm{GLU}_\phi(x)=\bigl(\phi(xW_g)\odot xW_u\bigr)W_d,\qquad W_g,W_u\in\mathbb{R}^{d\times d_{ff}},\; W_d\in\mathbb{R}^{d_{ff}\times d}.$$

输入 $x$ 先经过两个不同的线性投影，得到门控分支 $g=xW_g$ 和线性分支 $u=xW_u$。对 $g$ 应用激活函数，再与 $u$ 逐元素相乘，得到中间表示 $h=\phi(g)\odot u$；最后通过 $W_d$ 将中间表示投影为输出。SwiGLU、GeGLU、ReGLU 的区别，就在门控分支分别采用 SiLU、GELU、ReLU。

先看 SwiGLU 的一个中间通道

暂时不看最后的输出投影 $W_d$，只观察逐元素相乘这一步。取出一个通道后，$g$ 和 $u$ 都是一个数，这个通道的输出就是：

$$h=\mathrm{SiLU}(g)\,u=g\,\sigma(g)\,u.$$

这里的门控系数不局限于 0 到 1。$\mathrm{SiLU}(g)$ 可以为负，也可以大于 1，因此它既能减小信号幅度，也能翻转符号或放大信号。下面的热力图展示 $g$、$u$ 不同组合产生的 $h$：横轴改变门控输入 $g$，纵轴改变待传递的数值 $u$。

梯度：两个分支的梯度如何计算

训练时两个分支都会更新。记 $g=xW_g$，$u=xW_u$，$h=\phi(g)\odot u$，上游梯度为 $\delta=\partial L/\partial h$。那么

$$\frac{\partial L}{\partial u}=\delta\odot\phi(g),\qquad \frac{\partial L}{\partial g}=\delta\odot u\odot\phi'(g).$$

两条路径的梯度互为对方的函数：$u$ 的梯度被 gate 的输出 $\phi(g)$ 缩放， gate 的梯度被 $u$ 的大小缩放。这解释了 GLU 的一个训练特点，即 $g$ 和 $u$ 两个分支的数值尺度会互相放大，如果某个通道上两者同时变大，输出和梯度的幅度可能同时过大。在 SwiGLU 里 $\phi'(g)$ 在 $g$ 很大时趋近 1，$\phi(g)\approx g$，所以在较大的正输入区域，固定任一非零分支时，输出幅度可随另一分支近似线性地无界增长，这是 2025 年之后多个模型采用输出范围限制的动机之一。

从图中还能看出两个分支的multiplicative interaction：输出由门控分支和线性分支共同决定；当 $g$、$u$ 同时取很大的正值时，SwiGLU 的输出近似 $gu$。如果去掉非线性调制，两个线性投影的乘积 $(xW_g)_i(xW_u)_i$ 是输入的二次型；一般的 GLU 则包含非线性函数 $\phi$，更准确地说，它给 FFN 引入了multiplicative interaction。

从 GLU 到 SwiGLU：历史与实验

门控线性单元最早由 Dauphin 等人在 2016 年提出，$\phi=\sigma$。Shazeer 在 2020 年的短文里系统地试了 $\phi$ 取 sigmoid、ReLU、GELU、Swish 以及Bilinear（省略激活函数）的版本，发现在 T5 的设定下 GeGLU 和 SwiGLU 的预训练困惑度和下游任务都明显好于普通的 ReLU 或 GELU FFN。论文没有给出这些变体效果更好的理论解释。

参数量的对齐：为什么 $d_{ff}$ 是 $\tfrac{8}{3}d$

GLU 比普通 FFN 多一个矩阵。为了在同参数量下比较，Shazeer 把中间维度从 $4d$ 缩到 $\tfrac{2}{3}\cdot 4d=\tfrac{8}{3}d$，这样三个矩阵的总参数量 $3\cdot d\cdot\tfrac{8}{3}d=8d^2$ 恰好等于原来两个矩阵的 $2\cdot d\cdot 4d$。Llama 沿用了这个约定，并把结果向上取整到 256 的倍数：Llama 2 7B 的 $d=4096$，$\tfrac{8}{3}d\approx10923$，取整后是 11008。看到一个模型的 intermediate_size 大约是 hidden_size 的 2.7 倍，就可以判断它用的是 GLU 结构。不过这只是 Llama 一系的习惯，不是定律：Gemma 3 4B 的 hidden_size 是 2560，intermediate_size 是 10240，也就是 GeGLU 配 $4d$ 的宽度；Gemma 4 31B 同样是 5376 对 21504，比例不变。Google 从一开始就没有按同参数量去对齐。

工程形态

实际实现里 $W_g$ 和 $W_u$ 几乎总是被拼成一个 $d\times 2d_{ff}$ 的矩阵一次算完，激活函数和逐元素乘写在 GEMM 的 epilogue 里，或者由一个专门的 fused kernel 完成，这样中间结果可以减少中间结果写入显存后再读取的次数。vLLM、SGLang、FlashInfer 这类推理框架都有 silu_and_mul、gelu_and_mul 之类的算子，名字直接对应 SwiGLU 和 GeGLU。在训练侧，反向传播需要 $\phi(g)$、$\phi'(g)$ 和 $u$，通常只存 $g$ 和 $u$，在反向时重算 $\phi$，通过重计算减少保存激活值所需的显存。

08限制 GLU 的输出：2025–2026 年的共同选择

gpt-oss、DeepSeek-V4、Kimi K3 三家用了三种不同的办法解决同一个问题：SwiGLU 的乘积无界。

问题的表现是训练后期或者模型规模增大之后，FFN 中间层偶尔会出现极大的激活值，这类大幅值激活可能引发 loss spike（训练损失突然增大）；文献中的 massive activations 指部分维度的激活幅度远高于其他维度，不能仅凭数值大就认定是训练异常。在 MoE 里情况更糟：Kimi K3 从 896 个专家里每次只激活 16 个，每个专家只处理很小一部分 token，参数更新的方差大，个别专家的 $g$、$u$ 同时偏大并不罕见。既然 $\phi(g)\cdot u$ 没有固定的幅度上界，那限制其中一个或两个分支的数值范围就是最直接的办法。

gpt-oss：hard clamp 加偏置

$$h=\bigl(\tilde g\,\sigma(1.702\,\tilde g)\bigr)\odot\bigl(\tilde u+1\bigr),\qquad \tilde g=\min(g,7),\quad \tilde u=\mathrm{clip}(u,-7,7).$$

OpenAI 2025 年 8 月开源的 gpt-oss 做了三处改动。 gate 分支用的是 quick GELU 形式的 $\alpha=1.702$，并且只在上方截断到 7（该分支的输出在输入趋向负无穷时趋近零，因此没有设置下限）；线性分支两侧都截到 $\pm7$；线性分支还加了一个常数 1。加 1 后，输出可展开为 $\phi(\tilde g)\odot\tilde u+\phi(\tilde g)$；当 $\tilde u=0$ 时，输出仍为 $\phi(\tilde g)$。这三处改动都是逐元素的，对内核几乎没有额外成本。Hugging Face 上的 config.json 里对应的字段是 hidden_act: "silu" 和 swiglu_limit: 7.0，transformers 的 modeling_gpt_oss.py 里的实现只有四行：gate.clamp(max=limit)、up.clamp(-limit, limit)、glu = gate * sigmoid(gate * 1.702)、(up + 1) * glu。

DeepSeek-V4：SwiGLU clamping

DeepSeek-V4 的技术报告在「训练稳定性」一章里单独列出了 SwiGLU clamping，作为 loss spike 缓解手段之一。transformers 里 modeling_deepseek_v4.py 的采用与 gpt-oss 相同的 clamp 方式： gate 分支 clamp(max=limit)，线性分支 clamp(-limit, limit)，然后 act_fn(gate) * up；区别是没有那个「加 1」，阈值由 swiglu_limit 控制。DeepSeek-V4-Pro 的 config.json 里就是 hidden_act: "silu"、swiglu_limit: 10.0，384 个路由专家取 top-6 外加 1 个共享专家。同一份配置里还有一个值得留意的字段 expert_dtype: "fp4"，专家权重是以 4 比特存的；激活值有了明确的上界之后，低比特下的数值范围会好控制得多，这和第 12 节里「有界激活对量化更友好」是同一件事。同一份报告还把 MoE 路由的打分函数从 V3 的 sigmoid 换成了 $\sqrt{\mathrm{softplus}(\cdot)}$（配置字段 scoring_func: "sqrtsoftplus"，负载均衡 topk_method: "noaux_tc"），这一改动虽然不在 FFN 里，但同样是在挑一个「非负、单调、增长可控」的函数，我们在第 10 节讨论 softplus 时再回来看。

Kimi K3：SiTU-GLU，用 tanh 做 soft-capping

$$\mathrm{SiTU\text{-}GLU}(x)=\Bigl[\beta_1\tanh\bigl(\tfrac{g}{\beta_1}\bigr)\odot\sigma(g)\Bigr]\odot\Bigl[\beta_2\tanh\bigl(\tfrac{u}{\beta_2}\bigr)\Bigr],\qquad \beta_1=4,\;\beta_2=25.$$

Moonshot 对两个分支都使用 tanh soft-capping。 gate 分支里 SiLU 的那个 $x$ 换成了 $\beta_1\tanh(x/\beta_1)$，于是 gate 的输出被限制在 $(-\beta_1,\beta_1)$；线性分支同样用 tanh 压到 $(-\beta_2,\beta_2)$；乘积的绝对值上界就是 $\beta_1\beta_2=100$。在原点附近 $\beta\tanh(x/\beta)\approx x$，所以对于相对于阈值较小的输入它和 SwiGLU 几乎完全一样，主要在输入绝对值较大时发生变化。相比hard clamp，tanh soft-capping 的导数处处连续，饱和区域梯度是按 $1-\tanh^2$ 衰减而不是直接归零，这保留了连续变化的梯度；代价是每个元素多两次 tanh，不过在 MoE 专家这种带宽受限的算子里实际开销还取决于硬件和内核实现。Kimi K3 的 config.json 里可以直接看到这三个值：hidden_act: "situ"、activation_situ_beta: 4.0、activation_situ_linear_beta: 25.0，以及 num_experts: 896、num_experts_per_token: 16。

设计判断

阈值的位置比截断的形状更重要。在 $\beta$ 或 clamp 阈值远大于正常激活范围时，三种方案对大多数元素的影响可能较小，具体比例取决于激活分布，区别主要出现在激活值绝对值较大的区域；所以阈值要根据实际激活分布来定，阈值过小可能限制表达能力，过大则难以有效限制极端激活值。另外，这种截断是训练时就要有的，给一个已经训好的 SwiGLU 模型事后加 clamp 等于换了一个函数，需要重新校准。

09Squared ReLU：正半轴上的二次激活

GLU 在两个分支之间引入乘法。Squared ReLU 则直接对正输入求平方，使用普通 FFN 的输入、输出两个投影矩阵。

Squared ReLU

$$\mathrm{ReLU}^2(x)=\max(0,x)^2,\qquad \bigl(\mathrm{ReLU}^2\bigr)'(x)=2\max(0,x).$$

它来自 Google 2021 年的 Primer，那篇工作用进化搜索在 Transformer 的计算图上找改进，找到的两个最稳定的收益之一就是把 FFN 的 ReLU 平方。它的导数是 $2\max(0,x)$，在原点连续（值为零），比 ReLU 光滑了一阶；正半轴是二次增长，大的输入会被进一步放大，这在功能上与 GLU 的乘积类似，但只需要普通 FFN 的两个矩阵。NVIDIA 从 Nemotron-4 开始一直用它，Nemotron-H 和 2025 年底的 Nemotron 3 系列的 MoE 专家都是 Squared ReLU 配 sigmoid 路由，Nemotron 3 Nano 的配置里写作 mlp_hidden_act: "relu2"，128 个路由专家取 top-6，外加 1 个共享专家。它同时保留了 ReLU 的精确零，所以可以采用基于零激活值的稀疏推理方法。

它的局限也来自二次增长：没有任何上界，正半轴的导数随输入线性变大，对预激活值的尺度非常敏感。工程上通常靠 RMSNorm 控制输入的数值尺度，再依赖较小的初始化和learning rate warmup；从 Nemotron 系列多年一直沿用这个选择来看，这些问题在他们的训练配置下是可控的。

10Softplus：它出现的地方都需要一个正数

作为隐藏层激活它从来没流行过，但它是 ReLU 的光滑版，也是产生「保证为正」的量的标准工具。

$$\mathrm{softplus}(x)=\log\bigl(1+e^{x}\bigr),\qquad \mathrm{softplus}'(x)=\sigma(x).$$

它在现代架构里出现在三类位置。第一类是状态空间模型的步长：Mamba 用 $\Delta=\mathrm{softplus}(\cdot)$ 生成离散化步长，因为 $\Delta$ 必须为正，而且在大部分范围内希望它近似线性、在负半轴平滑地趋于零而不是hard clamp。第二类是可学参数的约束，比如各种需要「非负标量」的场景。第三类是 2026 年新出现的用法，DeepSeek-V4 把 MoE 路由的专家路由得分从 sigmoid 换成了 $\sqrt{\mathrm{softplus}(\cdot)}$：sigmoid 有上界 1，专家得分在饱和后无法再区分，而 softplus 无上界、开方后增长又比线性慢，既保留了大分数之间的差异，又不至于让路由权重过于集中。

数值上要注意 $\log(1+e^x)$ 在 $x$ 很大时会溢出，标准实现是当 $x$ 超过某个阈值（PyTorch 默认 20）时直接返回 $x$，或者写成 $\max(x,0)+\log(1+e^{-|x|})$ 这种稳定形式。

12怎么选

没有一个函数在所有目标上都最好。下面按最常见的几种处境给出判断。

如果你在训练一个常规规模的 dense 或 MoE 模型，可以优先评估 SwiGLU。它有最多的训练配置、最成熟的 fused kernel、最多的量化和推理框架支持，任何替代方案带来的收益都要先付出「生态不兼容」的成本。选 GeGLU 也没问题，两者的效果需在相同设置下比较，唯一要确认的是 GELU 用精确版还是 tanh 近似版，并且训练推理保持一致。

如果你的模型大到开始出现 loss spike，或者 MoE 的专家稀疏度很高，在设计阶段就限制 GLU 的输出范围。三种方案里，hard clamp 实现简单、内核改动最小；tanh soft-capping 的梯度更平滑，但需要多两次超越函数；gpt-oss 在线性分支加 1 的改动可以单独评估。阈值要从你自己的激活统计里定，不要照抄别人的 7 或者 25。

如果主要目标是降低推理成本，并且部署环境是带宽受限的（端侧、CPU、单卡跑大模型），可以评估利用激活稀疏性减少计算和访存。从头训练可以直接用 Squared ReLU 或 dReLU；已有 SwiGLU 模型可以做 ReLUfication 微调，需要继续训练，并评估对模型质量的影响。这条路的收益完全取决于推理引擎能不能真正跳过零对应的权重，应先确认推理框架是否支持。

如果你在做量化或者写推理内核，关注的不是 loss 而是数值范围和实现细节：有界的激活（clamp 过的 GLU、SiTU）对 W8A8 这类激活量化明显更友好；GELU 的两个版本不能混用；SiLU 的反向只需要存 sigmoid 值；Squared ReLU 的输出动态范围大，低比特激活量化要小心。

最后一条适用于所有情况：激活函数在这个领域里从来不是单独调的，它总是和归一化位置、初始化尺度、learning rate warmup、路由函数共同构成训练配置。换掉一个函数而不动其他部分，可能无法区分激活函数本身与其他配置不匹配造成的影响。
